[NordVPN](/ja/articles/nordvpn)と[Surfshark](/ja/articles/surfshark)は、どちらも日本語のサイトやヘルプを持ち、長期の前払いでVPNを売り、Deloitteの保証を挙げる。2本の解剖記事を重ねると、選ぶときに効く差は、更新のあとの額、端末の台数、誰と契約するか、外から確かめられる範囲に出ているとみられる。

この記事は両社の公式ページを2026年11月2日に読んでまとめた。比べられない点が1つある。`nordvpn.com`は当サイトのリクエストをCloudflareのチャレンジで拒否したため、NordVPNの料金ページの初回価格とプランの比較表は読めていない。当サイトは両方を契約して速度を測ってはおらず、速度の優劣は扱わない。金額は税の扱いを併記し、税抜の額で並べる。

## 会社：別々に運営すると説明する、1つのグループ

:::fact
NordVPNの利用規約（2026年8月10日更新）の契約相手はパナマのnordvpn S.A.で、パナマ法が適用される。日本の居住者の支払いは主に渋谷のNord Security JP Co., Ltdが処理するとされる。Surfsharkの利用規約の相手はオランダで設立されたSurfshark B.V.で、適用法は英領ヴァージン諸島の法律だ。どちらも、居住国の強行規定が優先しうることを書く。Nord Securityの2023年9月28日の発表は「2022年にSurfsharkとグループの企業を形成した」と書く。Surfsharkの会社概要は、両社が2022年に1つの持株会社の下で合併し、それぞれ独立したブランドとして運営するとし、2022年の公式ブログは別々のインフラと製品開発計画を持つ自律した会社として続けるとした。
:::

| 項目 | NordVPN | Surfshark |
| --- | --- | --- |
| 契約の相手 | nordvpn S.A.（パナマ） | Surfshark B.V.（オランダ） |
| 適用法 | パナマ法 | 英領ヴァージン諸島の法律 |
| 始まり | 2012年、リトアニア | 2018年、リトアニア |
| 日本の支払いの会社 | Nord Security JP Co., Ltd（渋谷）が主に処理と明記 | 当サイトが読んだ規約に日本の会社の記載なし |

:::pull
別のブランドとして選べるが、同じグループに属する。運営の資本から離れるための乗り換えなら、この2つの間では目的を果たさない可能性がある。
:::

## 料金：更新額の差と、読めた範囲

:::fact
NordVPNの更新料金のページ（2026年6月10日更新）は、日本の1年の更新額をBasic 21,960円、Standard 23,640円、Plus 28,320円、Complete 34,680円、Ultra 42,720円、Complete Max 45,960円とする（税は別）。Surfsharkの料金ページのHTMLに埋め込まれたデータ（2026-11-02取得）では、更新の欄がStarter 12,451円、One 15,603円、One+ 18,755円（税抜）で、この額は料金ページの本文には表示されない。Surfsharkの24か月プランはこの日「ブラックフライデー」の表示のもとで、3か月を足した27か月分がStarterとOneで8,046円、One+で16,146円（税抜）だった。NordVPNの初回は、ウェブの料金ページを読めていない。日本のApp Storeには12か月のプランが11,800円と9,300円、1か月のプランが2,100円と1,350円で並ぶが、条件の説明はない。Surfsharkの1か月プランはウェブでStarter 2,898円だ。両社とも更新の30日前に通知するとし（1か月プランを除く）、表示される更新価格がA/B価格テストの対象になりうると書く。
:::

| 税抜 | NordVPN（Basic） | Surfshark（Starter） |
| --- | --- | --- |
| 1年の更新額 | 21,960円（月1,830円） | 12,451円（月約1,038円） |
| 最上位の1年の更新額 | Complete Max 45,960円 | One+ 18,755円 |
| 長期プランの初回（ウェブ） | 読めていない | 27か月分 8,046円 |
| 更新額の置き場所 | 国別の固定の表（法務ページ） | スクリプトが描く別ページの表と、料金ページの埋め込みデータ |
| 返金保証 | 最初の購入の30日 | 最初の購入の30日 |

月あたりの額は当サイトの計算。Surfsharkの更新の額は当サイトが埋め込みデータから読み取った値で、取得の時刻によって変わることがある。NordVPNのApp Storeの額は税の扱いがページに書かれていないため、表には入れていない。

:::guess
読めた範囲では、1年ごとに使い続ける段階の額はSurfsharkのほうが低く、BasicとStarterの差は年9,509円になる（当サイトの計算）。ただし両者の内容は同じではなく、段階の名前も対応していない。一方で、更新額の確かめやすさはNordVPNの固定の表が上と読める。Surfsharkの額は取得の時刻によって動いたことがあり、利用者が確実に知る機会は更新前のメールとアカウントの画面になるとみられる。
:::

## 台数と日本からの使い方

:::fact
NordVPNのヘルプセンターは、1つの契約で同時に10台までとし、専用IPは東京を含む31の国と地域に拠点があるとする（当サイトの集計）。無料トライアルは日本を含む15か国で7日間、対象はPrime、Ultimate Max、Ultra、Complete Maxの1年・2年プランだ。Surfsharkの料金ページのよくある質問は台数無制限の同時接続をうたい（無料トライアル中は3台まで）、利用規約の公正利用の方針は、過度な数の端末を制限する権利を留保する。日本のサーバーのページは東京に80台、世界に100か国4,500台以上と書く。NordVPNの総数は、2025年5月の発表の118か国7,600台以上が読めた最新で、日本の台数は読めていない。Surfsharkの専用IPのページは日本語版で15か所の中に東京を挙げ、本文の別の箇所では20か所と書く。
:::

:::guess
家族の端末が10台を超えるなら、Surfsharkのほうが素直に収まる。10台に収まるなら、この差は判断の決め手にならないとみられる。東京の専用IPは両社にあるが、NordVPNの一覧は都市ごとに揃っている。日本のサーバーの台数を確かめたい人には、Surfsharkのページが具体的だ。
:::

## 記録と第三者の確認

:::fact
NordVPNのプライバシーの告知（2026年7月20日の版）は、インターネットの活動を記録せず、最後のセッションの情報をセッション終了後15分以内に自動で削除し、過去90日間に使ったかどうかの情報を処理するとする。Surfsharkの個人情報保護方針（2026年10月12日更新）は、ユーザーID、IPアドレス、接続のタイムスタンプなどをセッション終了後15分以内に自動で削除するとする。保証は、NordVPNが2018年、2020年、2022年、2023年に続く5度目をDeloitte Audit Lithuaniaに依頼し（2025年2月18日発表、ISAE 3000）、Surfsharkは2025年6月16日の公式ブログでDeloitteの再度の保証を告げる（詳しい報告書はISAE 3000で、アカウントで読める）。NordVPNの報告書も、ログインした利用者が読める。当サイトはどちらの全文も読んでいない。
:::

:::fact
公開するコードでは、NordSecurityの組織がGitHubでLinuxクライアントの`nordvpn-linux`とネットワークのライブラリ`libtelio`をGPL-3.0で公開する。Surfsharkのトラストセンターは、100%RAMのサーバーと監査の一覧を挙げる。プロトコルは、NordVPNがWireGuardを土台にしたNordLynx、制限されたネットワーク向けのNordWhisper、OpenVPNなどを持ち、ポスト量子暗号は全アプリのNordLynxで設定から有効にできる。Surfsharkは独自のDausos（現在はmacOS版のアプリ）、WireGuard、IKEv2、OpenVPNを持つ。
:::

:::guess
どちらのノーログも、各社の説明と、その説明を対象にした保証の結果として受け取るのが妥当とみられる。両社の差は、NordVPNが評価の回数とクライアントのコードの公開で、Surfsharkがサーバーの作りと第三者の評価の一覧の示し方で、それぞれ信頼を補っている点にあると読める。当サイトが`nordvpn.com`を読めていないため、NordVPNのサーバーの作りについてはここで比べていない。
:::

## 紹介の仕組み：どちらも割引の掲載に許可が要る

:::fact
Surfsharkのアフィリエイトのページは、新規売上の40%から始まる収益分配、Cookieの有効期間30日、最低支払額100ドルを挙げる。NordVPNのアフィリエイトの規約は、Cookie 30日、最低支払額100ドル、返金やチャージバックによる取り消しを定め、報酬の率はヘルプセンターによればプランで変わる（率を書いたページは読めていない）。どちらの規約も、ブランドの語への入札を禁じ、事前の書面の許可なく返金・クレジット・割引を掲載することを禁じる。ポップアップ広告は、NordVPNは禁止、Surfsharkは書面の許可がある場合を除いて禁止だ。
:::

:::guess
規約の骨格はよく似ており、同じグループだからとも、業界の標準的な書き方だからとも読める。紹介の記事を読む側は、両社とも紹介者に報酬を払う仕組みがあり、割引の表示も管理されていることを踏まえて読むのがよい。
:::

## 技術構成の重なり

このページの下に出る技術構成の比較は、2本の記事のtechStackを機械的に突き合わせたものだ。共通と判定された項目の使いどころは、各記事の技術構成で扱っている。

どちらを選ぶかは、次のように分けられそうだ。使い続けるときの年額を抑えたい、端末が10台を超える、VPNに詐欺対策などを安く足して始めたいならSurfshark。更新額を固定の表で先に確かめたい、Linuxでコードの公開されたクライアントを使いたい、東京を含む専用IPの一覧を見て選びたい、Next-gen antivirusのようなOS側の保護を試したいならNordVPNが候補になる。NordVPNの初回価格は当サイトでは比べられなかったので、申し込む前に料金ページと決済の画面で、初回の総額、更新額、税を3つとも確かめておきたい。どちらを選んでも、同じグループの中の選択だということは覚えておくとよい。
