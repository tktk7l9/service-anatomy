[楽天証券](/ja/articles/rakuten-securities)と[SBI証券](/ja/articles/sbi-securities)は、料金表だけを並べると驚くほど同じ顔をしている。国内株式の手数料は0円、米国株式は税込0.495%で上限22ドル、信用取引の買方金利は年2.80%。競争が進んだ結果、数字は揃ってしまった。だから比べるべきなのは、率そのものより、0円になる条件、ポイントとカードの陣営、そして事故が起きたときの説明の書き方だ。この記事は、両社の公式ページと決算資料を2026年11月2日に読み、書かれている内容を並べる。当サイトは両社の口座を開いて使った体験を書いているのではない。料金や条件は変わるので、申し込む前に必ず公式ページを確認してほしい。投資には価格の変動などで損失が生じるおそれがあり、本記事は投資を勧めるものではない。

## 規模と決算を同じ半年で並べる

楽天証券は12月決算、SBI証券は3月決算なので、通期の数字をそのまま比べられない。楽天証券の第3四半期のお知らせが2026年4〜9月の参考情報を載せているので、SBI証券の中間決算と同じ半年で並べられる。

:::fact
以下は、楽天証券の決算資料とSBI証券の決算短信・決算説明資料に書かれている数字を、当サイトが並べ直したものだ。営業利益率と倍率は当サイトの計算。SBI証券の数字にはグループのネット証券を含むものがあり、対面やIPOの引受などの事業も含むので、個人のネット取引だけの比較ではない。

| --- | --- | --- |
| 営業収益（2026年4〜9月・連結） | 1,156億6,000万円 | 1,910億1,300万円 |
| 営業利益（同） | 404億6,800万円 | 668億6,600万円 |

SBI証券の決算説明資料は、2026年4〜6月期の営業収益の構成比を両社について示している。委託手数料はSBIが12.1%、楽天が16.8%、金融収益はSBIが41.5%、楽天が44.4%、トレーディング損益はSBIが23.7%、楽天が18.6%だ。

:::guess

:::

## 手数料が0円になる条件

:::fact
楽天証券の公式ページ（2026-11-02閲覧）によれば、ゼロコースはインターネットでの国内株式（現物・信用）の取引手数料が約定代金にかかわらず0円。原則として同社が指定するSOR注文の利用が必須で（指定の取引ツールや注文形態で発注する場合を除く）、コースの設定にはSORとRクロス（同社の社内取引システム、ダークプール）の内容を理解して同意する必要がある。SORの接続先は東証、JAXPTS、ジャパンネクストPTS、Rクロスの最大4市場だ。

SBI証券の手数料ページ（2026-11-02閲覧）によれば、スタンダードプランでもアクティブプランでも、条件を満たせば「ゼロ革命」の対象となり、約定代金にかかわらず国内株式の取引手数料が0円になる。電子交付サービスを申し込んでいない顧客は対象外と明記されている。

条件を外れた場合の料金は近い。1約定の手数料は、楽天の超割コースが5万円まで55円、10万円まで99円、3,000万円超で1,070円（いずれも税込）。SBIのスタンダードプランの現物の表も、同じ行で同じ金額だ（税込55円、税込99円、税込1,070円）。
:::

:::fact
その他の取引の料率は次のとおりだ（いずれも2026-11-02閲覧の公式ページによる）。

| 項目 | 楽天証券 | SBI証券 |
| --- | --- | --- |
| 米国株式（現物・課税口座） | 約定代金の0.495%（税込）、上限22米ドル（税込） | 約定代金の0.45%（税込0.495%）、上限20ドル（税込22ドル） |
| 最低手数料が0ドルになる約定代金 | 2.22米ドル以下 | 2.02米ドル以下 |
| 米国株式信用取引の取引手数料 | 無料（オペレーター取次を除く） | 0米ドル |
| 国内株の買方金利（制度信用） | 年2.80%（優遇2.28%） | 通常2.80%（優遇2.28%） |
| 国内株の買方金利（一般信用） | 年2.80%（優遇2.10%） | 通常2.80%（優遇2.10%） |
| 日計りの金利 | いちにち信用は年0.00% | 1注文100万円以上は0%、100万円未満は買方金利・貸株料とも年1.80% |
| 単元未満株 | かぶミニは手数料無料。リアルタイム取引に0.22%のスプレッド、寄付取引はスプレッド無料 | S株は買付・売却手数料とも無料 |

NISAでの米国株式などの手数料は、楽天の公式ページは日米株式の取引手数料無料と案内している。SBIの案内ページも米国株式の売買手数料の無料を掲げている。
:::

:::guess
無料の条件の違いは、両社が何を手に入れたかったのかの違いとして読めるとみられる。SBIの条件は電子交付で、紙の書面を減らす方向に顧客を寄せるものだ。楽天の条件はSORとRクロスで、注文を自社が設計した執行経路に乗せるものだ。使う側から見ると、SBIは書面を電子で受け取ると決めれば済み、楽天は執行の仕組みを理解して同意するひと手間がある。どちらの執行が有利かは銘柄と時間帯で変わるので、この比較からは言えない。
:::

## カードとポイントの陣営

:::fact
クレカ積立はどちらも毎月100円から10万円までで、ポイントの率の決まり方が違う。

| 項目 | 楽天証券 | SBI証券 |
| --- | --- | --- |
| 対象カード | 楽天カード（みずほ楽天カードも対応） | 三井住友カードなど |
| 主なポイント | 楽天ポイント | Vポイント（SBI証券はほかにPonta・d・PayPay・JALのマイルから選択可） |
| 率の決まり方 | カードの種類と銘柄の代行手数料で決まる | カードの種類と年間カード利用額で決まる |
| 入門カードの率 | 楽天カード0.5%（代行手数料年率0.4%以上の銘柄は1%） | 三井住友カード（NL）は年間利用額10万円以上で0.5%、10万円未満は0% |
| 表示上の最大 | 2%（ブラックカード）。2027年1月買付分から最大3.2% | 最大6%（カード別の最大4%に、Olive資産運用サービスの条件達成で最大2%を上乗せ） |

楽天にはこのほかに楽天ペイ残高決済（毎月最大5万円、0.5%）がある。楽天ブラックカードの3.2%は前年のショッピング利用額400万円以上が条件で、楽天証券の投資信託のクレカ積立分は利用額に含まれない。SBI側も、クレカ積立額は年間カード利用額の集計対象にならない。楽天は投信残高ポイントの対象を楽天・プラスシリーズなど6本とし、それ以外は残高が基準に初めて達したときに付与する。SBIの投信マイレージは通常銘柄で0.1%（月間平均保有金額1,000万円以上は0.2%）などファンドごとの付与率で、SBIのページは幅広いファンドが対象だと説明している。
:::

:::fact
ポイントで買えるものも案内が違う。楽天のページによれば、楽天ポイントは1ポイント1円で投資信託、国内株式（現物）、米国株式（円貨決済）、バイナリーオプションの購入に使える。投資信託や米国株式を月3万円以上ポイントで買うと楽天市場のSPUが上がる。SBIのページは投資信託や国内株式の買付・積立にポイントを使えるとしている。銀行との連携では、楽天のマネーブリッジは2026年11月2日時点で普通預金1,000万円以下の分に年0.58%を適用する。
:::

:::guess
ポイントの比較で見るべきなのは、最大の率よりも、自分のカード利用額がどの行に当たるかだ。SBIの最大6%は、年会費の高いカードと年間の利用額、さらにOliveの条件を重ねた数字で、入門カードの多くはずっと低い率になる。楽天の率は利用額に関わらず決まるカードが多く、年間のカード利用が少ない人でも0%になりにくい。逆に、三井住友カードで日々の支払いをしている人は、SBIのほうが表の上側の行に届きやすいとみられる。すでに持っているカードの陣営が、そのまま答えになることが多いと推測される。
:::

## 不正アクセスへの説明と認証

:::fact
楽天証券の補償方針（2025-07-25、2026-02-18更新）は、被害額の50%を基本に金銭で補償し、売買手数料を返金し、一律1万円のお見舞金を支払うとする。元々保有していた有価証券の不正な売却は被害額の算定対象外で、お見舞金の対象になる。SBI証券の補償方針（2025/10/25以前の分）も、原則として被害の50%の金銭補償で、売買手数料などの費用は全額補償し、一律のお見舞金を支払い、被害が保有有価証券の売却のみの場合は費用とお見舞金が補償内容だとする。2025年5月2日に日本証券業協会が公表した証券会社10社の申し合わせがこの枠組みの背景にあるとSBIは説明している。

違いが出ているのは、認証を強化したあとの扱いだ。SBI証券は2025年10月25日にパスキー認証を導入し、2025年10月26日以降の被害については、ID・パスワードの管理やセキュリティ機能の利用状況などに応じて個々に検証のうえ補償の有無と内容を決める方針へ改めたと明記している。楽天証券は2025年10月26日にパスキーを全チャネルへ導入し、2026年6月から必須化を段階的に実施している。パスキー設定後は併用できない形だ。SBIのFAQは、パスキーは2026年6月30日から原則必須だが、引き続きユーザーネームとパスワードでもログインでき、設定までの間は案内を表示するとしている。

楽天証券は2026年10月31日に、外部サービス提供元の委託先への不正アクセスで「デジタル特典付き社債」を購入した一部の顧客情報、延べ362件が持ち出された可能性があると公表した。同社のシステムが受けたものではないとしている。

## 親会社と提携先

:::fact
楽天証券の株主は楽天証券ホールディングス（51.0%）とみずほ証券（49.0%）で、楽天証券ホールディングスは2026年10月1日に楽天銀行の連結子会社となった。SBI証券の決算説明資料と決算短信は、Oliveでの資産運用を支えるOliveコンサルティングの業務開始（2026年5月）や、地方銀行との金融商品仲介（山口FG傘下の銀行、福岡銀行、熊本銀行、十八親和銀行）の開始を主な取り組みに挙げている。楽天証券の主な連携先は楽天カード、楽天銀行のグループ内と、みずほ銀行・みずほ証券だ。
:::

:::guess
両社の違いを一言で言えば、閉じた経済圏と、開いた提携網だとみられる。楽天はカード、銀行、ポイント、EC、モバイルをグループ内に持ち、総合口座の86.7%が楽天会員という数字が示すように、もともとの楽天の顧客を証券へ運んでいる。SBIはカード、ポイント、銀行、地銀と、他社の顧客基盤へ広く接続している。ただし楽天にもみずほという外の相手が入り、SBIにもSMBCという特定の濃い相手がいるので、きれいな二分法ではなくなりつつある。
:::

## どんな使い方にどちらの条件が当てはまるか

ここからは、上の条件を当サイトが読んだうえでの整理だ。投資をするかどうかの判断ではなく、すでに口座を開くと決めた人が、公式の条件のどの行を読めばよいかを示す。

:::guess
- 普段の買い物が楽天市場で、楽天カードと楽天銀行を使っている人は、楽天証券の条件が当てはまりやすいとみられる。カードの年間利用額に関わらず0.5%以上の行が読め、SPUやマネーブリッジも同じ会員のまま使える。
- 三井住友カードやOliveを日常の決済に使い、年間の利用額が多い人は、SBI証券の表の上側の行に届きやすいと推測される。逆に年間のカード利用が10万円に届かない場合は、付与率が0%になる点を確認したい。
- 楽天のポイントを持っていない、または他のポイントを貯めている人は、SBIのポイント選択のほうが自由度が高い。PontaやdポイントやJALのマイルを貯めたい場合はSBIの案内を読むことになる。
- 信用取引の残高を大きく持つ人は、金利の行が同じなので、取扱銘柄や一般信用の在庫、優遇の条件で比べることになる。この記事では在庫までは比較していない。
- 日計りの信用取引を少額で繰り返す人は、楽天のいちにち信用は年0.00%、SBIは1注文100万円未満なら年1.80%という行の違いが効く可能性がある。
- 紙の書面を受け取りたい人は、SBIの無料の対象から外れる。注文の執行経路への同意を避けたい人は、楽天のゼロコースの対象から外れる。手数料の条件は、ここで分かれる。
- 両方に総合口座を持つこともできる。ただし楽天証券のNISAのページによれば、同じ年に開設できるNISA口座は1人につき1つの金融機関に限られるので、NISAだけはどちらか1つを選ぶことになる。
:::

## なぜ似た数字に行き着いたのか

:::guess
2社の料金表が揃っているのは、一方が下げれば他方が追う競争を長く続けた結果とみられる。手数料が0円に行き着くと、残るのは残高から得る収益で、それを増やす手段は口座と積立の数になる。だからどちらもカードとポイントに投資し、NISAの入口を競い、信用取引の残高に支えられる形になった。

ここで違うのは、残高を運んでくる道路を誰が持っているかだ。楽天は自前の道路を持っているので、費用の一部はグループの中で回る。SBIは他社の道路に接続するので、接続先が増えるほど広がる。楽天の販管費に占める取引関係費は2026年1〜6月で62.3%、SBIは2026年4〜9月で31.2%と大きく違うが、費用の区分が会社ごとに違う可能性があり、単純には比べられない（割合は当サイトの計算）。それでも、数字の差が2社の組み立ての差を映している可能性はある。
:::

楽天証券とSBI証券は、同じ0円を別の道筋で実現している。料金表の数字がほとんど同じになった今、選ぶときに読むべきなのは、率の行より条件の行だ。普段の支払いがどちらの陣営にあるか。書面と執行のどちらに同意できるか。事故のときの説明をどう読むか。その答えを持って公式ページを開けば、どちらの条件が自分の使い方に当てはまるかは見えてくる。
