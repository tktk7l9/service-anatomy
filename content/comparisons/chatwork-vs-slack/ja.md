[Chatwork](/ja/articles/chatwork)と[Slack](/ja/articles/slack)は、どちらも「仕事の連絡をチャットに移すサービス」として並べられる。ただし料金表を横に置くと、有料にすると何が変わるかの設計が違う。この記事は、日本向けの公式ページを2026年11月2日に読み、書かれている数字と条件をそのまま並べる。当サイトは両サービスを契約して使い比べた体験を書いているのではなく、公開されている料金表とドキュメントを突き合わせている。料金や条件は改定されるので、申し込む前に必ず公式ページを確認してほしい。

## 日本の料金を並べる

:::fact
以下は、Chatworkの料金ページとSlackの料金ページ（いずれも2026-11-02閲覧）を当サイトが並べ直したものだ。Chatworkの価格は税抜と明記されている。Slackはヘルプセンターで、ウェブサイトの料金に税は含まれず、請求先住所が日本国内なら消費税が課税されると説明している。

| プラン | 年払いの1ユーザー月額 | 月払いの1ユーザー月額 |
| --- | --- | --- |
| Chatwork フリー | 0円 | 0円 |
| Chatwork スタンダード | 700円 | 840円 |
| Chatwork プロフェッショナル | 1,200円 | 1,440円 |
| Slack フリー | 0円 | 0円 |
| Slack プロ | 925円 | 1,050円 |
| Slack ビジネスプラス | 1,920円 | 2,160円 |
| Slack Enterprise+ | 5,760円 | 表示なし |

Chatworkは、プロフェッショナルの最小ユーザー数を5ユーザーとしている。スタンダードの注記に最小人数は見当たらず、kubellの決算説明資料は最低利用人数を1人に変更したと説明している。Slackのプロとビジネスプラスの月払いには、チーム作成から7日以内の購入で3か月間50%オフになる期間限定オファーの表示がある。
:::

:::fact
上の年払いの単価から、30人で1年使う場合の税抜の金額を当サイトが計算すると次のようになる。Slackの50%オフは含めていない。

| プラン | 30人・1年の税抜の金額 |
| --- | --- |
| Chatwork スタンダード | 252,000円 |
| Slack プロ | 333,000円 |
| Chatwork プロフェッショナル | 432,000円 |
| Slack ビジネスプラス | 691,200円 |
| Slack Enterprise+ | 2,073,600円 |
:::

:::fact
課金の数え方も違う。Chatworkの料金ページの注記は、フリーからのアップグレードは組織内の全ユーザーが対象で一部のユーザーだけはできず、ユーザー数とライセンス数が異なる場合はライセンス数に基づいて料金が発生すると書く。アップグレード後はフリーに戻せない。Slackのフェアビリングポリシーは、ウェブサイト経由のプランではアクティブなメンバーだけに請求し、非アクティブになった分は日割りのクレジットにすると書く。アクティブの判定は、28日間のいずれかの時点でSlack上で行動したかどうかだ。Slackはフリーへのダウングレードができ、その影響を説明するページを用意している。
:::

:::guess
料金表の率だけを見ると、同じ段の比較ではChatworkが安く、スタンダードとプロの差は年払いで1人月225円だ。ただし全員が毎月使うとは限らない組織では、Slackのアクティブ課金によって実際の請求額が縮む余地がある。逆に、ほぼ全員が毎日使う組織なら、この差は小さくなるとみられる。消費税の扱いは事業者によって異なるので、税理士に確認するのが確実だ。
:::

## 無料プランで何が止まるか

:::fact
両社の公式ページ（2026-11-02閲覧）から、無料プランの主な制限を並べた。

| 項目 | Chatwork フリー | Slack フリー |
| --- | --- | --- |
| メッセージの閲覧 | 直近40日以内 | 直近90日まで |
| 古いデータ | 料金ページに削除の記載は確認できなかった | 1年を超えると順次削除（2024年8月26日から）。削除後は復元できない |
| 有料化で過去が戻るか | 有料プランはメッセージ閲覧が無制限 | 90日を超えて1年以内の275日分は読めるようになる |
| ユーザー数 | 1組織100人まで | 料金ページに上限の記載は確認できなかった |
| 社外とのつながり | 組織外のコンタクトは1ユーザー20人まで | Slackコネクトは1対1のDMのみ |
| 通話 | 1対1 | 1対1のハドルミーティング |
| 外部アプリ | 確認できなかった | 10個まで |
| 広告 | 表示あり（有料で非表示。自社とグループ会社の案内は対象外） | 料金ページに記載は確認できなかった |

ストレージは、Chatworkのフリーが組織で10GB、有料が1ユーザー10GBと明記されている。kubellの決算説明資料によれば、Chatworkのフリープランは2022年10月に閲覧制限を新設し、2024年8月に閲覧数の制限を撤廃してストレージを増やし、コンタクト数の制限を加えた。
:::

:::guess
無料プランの差は、40日と90日という日数より、どの時点で乗り換えを迫られるかにあると考えられる。Chatworkは過去の閲覧が短い代わりに、社外の20人までとグループチャットでつながり続けられる。Slackは90日分が読める代わりに、1年を超えた分は有料にしても戻らないので、記録として残したい会話があるなら早めに判断する必要がある。無料のまま長く使い続ける前提なら、どちらも業務の記録の置き場にはしないほうが安全だ。
:::

## 社外の人とのつなぎ方

:::fact
Chatworkの有料プランはコンタクト数が無制限で、料金ページの言葉では「組織外」の人とも1ユーザーあたりの上限なくつながれる。Slackは料金ページによれば、プロ以上でDM、グループチャット、最大250のオーガナイゼーションが参加できる専用チャンネルを通じて外部と連携できる（Slackコネクト）。フリープランに切り替えるとSlackコネクトのチャンネルは切断され、1対1のDMに限られる。別の手段としてゲストがあり、シングルチャンネルゲストは無料、マルチチャンネルゲストは有料で、フリーに戻すとすべて無効になる。
:::

:::guess
社外との連絡が多い会社にとって、差は「相手に何を求めるか」に出るとみられる。Slackコネクトは相手のオーガナイゼーションもSlackを使っている前提の仕組みで、相手が有料プランかどうかで使える範囲が変わる。Chatworkのコンタクトは個人同士をつなぐ形なので、取引先の相手が個人事業主や小さな事務所でも始めやすいと推測される。逆に、社外の組織と専用チャンネルを管理者の統制下で持ちたい大きな組織には、Slackコネクトの設計が合いやすいと考えられる。
:::

## AIの積み方

:::fact
Chatworkの料金ページは「要約/資料作成などのAI機能」をスタンダード以上の機能として挙げる。kubellの決算説明資料（2026-08-14）は、AI要約、AI下書き作成、AI労働・雇用ニュース、AI解説・分析、AI資料作成をリリースしたと説明し、今後は反響に応じて拡充するとしている。
:::

:::fact
Slackのヘルプセンターによれば、プロは会話とスレッドの要約、ハドルミーティング議事録の2つ、ビジネスプラスは検索、まとめ、翻訳、ファイルの要約、ワークフローの自動化を加え、Enterprise+はエンタープライズ検索を加える。パーソナルAIエージェントのSlackbotは、ビジネスプラスで1人週15通まで、フリーとプロはトライアルかプレビューの間だけ、Enterprise+は週や無期限の回数制限がない。超過分はSalesforceのFlex Creditsで購入できる。
:::

:::guess
Chatworkは「日常のチャットで困る場面」にAIを足し、Slackは「組織の知識をどこまで横断して読むか」でAIを段階にしているとみられる。Chatworkの労働・雇用ニュースのような機能は、法改正を追う担当者のいない中小企業に向いた発想と読める。Slackは組織に溜まった会話とつないだ外部システムを読むほど価値が上がる設計で、会話の量が多く、ビジネスプラス以上に払える組織ほど恩恵が大きいと推測される。プロのまま使うと、Slackの看板であるAI検索やSlackbotは継続的には使えない点に注意が要る。
:::

## APIと連携の開き方

:::fact
ChatworkのAPIドキュメントは、リクエスト数を5分あたり300回までと明記し、残り回数をレスポンスヘッダーで返す。APIトークンはHTTPヘッダーで送り、有効期限がない。公式のChatwork MCP ServerはGitHubでTypeScript・MITで公開されている（2026-11-02時点のAPIでスター51）。
:::

:::fact
SlackのWeb APIは、メソッドごとにTier 1（毎分1回以上）からTier 4（毎分100回以上）までの制限を持ち、ワークスペースとアプリごとに評価され、全プランで同じだ。ただしMarketplaceの外で商業配布するアプリでは、2025年5月29日以降に作られたアプリと新規インストールについて、conversations.historyとconversations.repliesが毎分1回、1回15件に制限された。社内で作るカスタムアプリは毎分50回以上、1回1,000件のままだ。API利用規約は、組織外に提供するアプリについて大規模言語モデルの学習と一括エクスポートを禁じる。Slack MCP ServerはMarketplace公開アプリと社内アプリが使え、Claude.ai、Claude Code、Perplexity、Cursorなどの提携クライアントからも使える。
:::

:::guess
自社の中だけで通知や集計を自動化するなら、どちらのAPIでも足りることが多いとみられる。差が出るのは、そのつなぎ込みを商品として他社に配りたい場合だ。Slackは審査を通ったMarketplaceを実質的な条件にしており、配布の手間は増えるが、2,600種類を超えるアプリの市場に載る。当サイトが読んだChatworkのAPIドキュメントの範囲では同様の審査の記載は確認できず、始めやすい一方で、届く先は国内の利用者が中心になると推測される。
:::

## データの置き場とセキュリティ

:::fact
Slackのデータレジデンシー機能は、東京を保管地、大阪をバックアップ地として選べる地域に含む。ヘルプセンターによれば、フリーやプロは先にビジネスプラスへのアップグレードが必要で、利用は営業担当者への申し込みになる。Chatworkのセキュリティページは、通信の暗号化とアップロードファイルの暗号化、2段階認証を説明し、IPアドレス制限、モバイル端末制限、チャットログのエクスポートなどをプロフェッショナルプランの機能として挙げる。データの保管地域は、当サイトが読んだChatworkの公式ページでは確認できなかった。
:::

## どんな組織にどちらが合いやすいか

ここからは、上の料金表と条件を当サイトが読んだうえでの整理だ。優劣を付けるものではなく、組織の形ごとに、どの行が効いてくるかを示す。

:::guess
- **社員が数人から数十人で、連絡相手に社外の個人が多い会社**は、Chatworkの料金表が当てはまりやすいとみられる。スタンダードで閲覧とコンタクトが無制限になり、AIも付いて1人月700円で収まる。kubellの決算説明資料は、有料ユーザーの97%が中小企業だと書いている。
- **社内の議論を残して後から検索し、複数のSaaSを通知でつなぎたい開発組織やIT企業**は、Slackのプロから始める形が考えられる。アプリの市場とWeb APIの厚みが効き、使わない人の分はクレジットになる。
- **組織の知識をAIで横断して検索したい会社**は、Slackのビジネスプラス以上を検討する余地がある。1人月1,920円でも、AIの回数制限まで読んで見積もる必要がある。
- **監査や端末制限が必要だが、費用を抑えたい中小企業**は、Chatworkのプロフェッショナルが候補になる。IPアドレス制限やチャットログのエクスポートが月1,200円に含まれる。
- **データの保管地を日本に指定する必要がある大きな組織**は、公開情報で確認できる範囲ではSlackの機能が明示されている。Chatworkについては個別に問い合わせて確かめる必要がある。
- **有料化してから様子を見て戻す可能性がある場合**は、Chatworkはフリーへ戻せないと明記している点に注意が要る。Slackは戻せるが、Slackコネクトの切断やワークフローの停止が伴う。
:::

## なぜ線の引き方が違うのか

:::fact
kubellの決算説明資料（2026-08-14）によれば、2026年6月末のChatworkの課金IDは84.9万、ARPUは734.5円で、kubellの2026年4〜6月の売上高のうちSaaSドメインは前年同期比+5.0%、チャット経由で業務を請け負うBPaaSドメインは+84.0%だった。Salesforceの決算資料によれば、Slackの売上は単独で開示されず、SlackbotはAgentforceのARRに含まれる。
:::

:::guess
線の引き方の違いは、2つの会社がチャットの先に何を見ているかの違いから来ているとみられる。kubellにとってチャットは、中小企業の業務を受け付ける窓口で、利用者を広く保つことに意味がある。だからAIは安い段に含まれ、差はセキュリティと管理に置かれ、収益の伸びはチャットの外に求められる。SalesforceにとってSlackは、組織の文脈が溜まる場所であり、AIエージェントの入口だ。だから線は「どれだけ読めるか」に引かれ、上位プランとFlex Creditsへの導線になる。

どちらの設計も、利用者から見れば筋が通っている面と不便な面がある。Chatworkは分かりやすいが、チャットそのものの機能差は小さく、案内が増える可能性がある。Slackは強力だが、段階と回数が重なり、見積もりに手間がかかる。両社とも今後の料金や機能を変える可能性があるので、数年単位の前提にはしないほうがよい。
:::

ChatworkとSlackは、同じチャットを別の目的で売っている。選ぶ側が見るべきなのは1人あたりの月額の差より、自分たちの会話が誰と交わされ、何年後に誰が読むのかだ。社外の小さな相手とすぐ話すことが中心ならChatworkの料金表が、社内に溜まった会話を検索とAIで使い回すことが中心ならSlackの料金表が、読むべき行を教えてくれる。
