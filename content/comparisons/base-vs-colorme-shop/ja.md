[BASE](/ja/articles/base)と[カラーミーショップ](/ja/articles/colorme-shop)は、どちらも国内の会社が運営するネットショップ作成サービスで、どちらにも月額0円のプランがある。初めてショップを開く個人や小さな事業者が2つを比べるとき、「無料」という言葉だけでは違いが見えない。公式ページを並べて読むと、違うのは、売れたお金がどこを通り、いつ、何を引かれて手元に届くかだ。

この記事は、2026年10月3日に両社の公式ページとヘルプページを読んで確認できた内容だけで書いている。当サイトは両サービスを契約して使ったわけではなく、使い心地の評価はしない。料金や条件は変わるので、申し込む前に必ず公式ページで確かめてほしい。

## 料金を並べる（2026年10月3日時点）

:::fact
BASEの料金ページによれば、プランはスタンダードとグロースの2つ。スタンダードは初期費用・月額費用とも0円で、商品が売れたときに決済手数料3.6%+40円とサービス利用料3%がかかる。グロースは初期費用0円、月額16,580円（年払いの1か月あたり。月払いは19,980円）で、決済手数料2.9%、サービス利用料0円。どちらも、決済方法がPayPay、Amazon Pay、PayPalの場合は決済手数料に1%が加わる。よくある質問は、グロースの契約期間を1か月か12か月から選べ、12か月一括払いは「198,960円（税込）」だと書き、スタンダードとグロースはいつでも切り替えられるとしている（グロースへの変更は即時、スタンダードへの変更はグロースの契約期間の終了後に反映）。ヘルプのグロースプランのページは、月払いを「19,980円（1ヶ月あたり・税込）」、年払いを「16,580円（1ヶ月あたり・税込）」と書き、月額費用の支払い方法はクレジットカードのみとしている。プランによる違いは手数料の料率だけで、使える機能に違いはないと説明されている。
:::

| BASE | 初期費用 | 月額 | 売れたときの手数料 |
| --- | --- | --- | --- |
| スタンダード | 0円 | 0円 | 決済手数料3.6% + 40円、サービス利用料3% |
| グロース（月払い） | 0円 | 19,980円 | 決済手数料2.9% |
| グロース（年払い） | 0円 | 16,580円（年198,960円） | 決済手数料2.9% |

:::fact
カラーミーショップの料金ページによれば、有料プランはレギュラー、ラージ、プレミアムの3つで、別に月額0円のフリープランがある。ページには「価格表記はすべて税込です」と注記があり、販売手数料は有料3プランとも0円。有料プランの契約期間は3・6・12か月から選ぶ。レギュラーとラージには30日間の無料体験がある。フリープランからレギュラー以上へは管理画面から変更できるが、レギュラー以上からフリープランへは変更できず、もう一度フリープランを使うにはアカウントを新しく作る必要がある。
:::

| カラーミーショップ | 初期費用 | 月額 | カード決済手数料 |
| --- | --- | --- | --- |
| フリー | 0円 | 0円〜 | 6.6% + 30円〜 |
| レギュラー | 3,300円 | 4,950円 | 3.4%〜 |
| ラージ | 3,300円 | 9,595円 | 3.19%〜 |
| プレミアム | 22,000円 | 35,640円〜（比較表の月額費用欄は39,600円） | 2.99%〜 |

:::fact
同じページの注記によれば、決済サービスを使うには決済代行会社との契約が別に必要で、表の決済手数料は決済プラン「カラーミーペイメント」を契約した場合の料金を参考にしたものだ。プレミアムプランのページは月額を「35,640円〜」とし、長期契約で月額費用が割引になると説明している。
:::

:::fact
公式の告知（2026-09-09）によれば、2026年11月1日以降、レギュラープランは月額4,950円から5,940円に、ラージプランは9,595円から11,000円に改定され、プレミアムプランは変わらない。契約開始日が11月1日より前なら改定前の料金になる。契約開始日が11月1日以降の場合は、契約更新・支払いの操作を11月1日より前に済ませれば改定前、11月1日以降なら改定後の料金になる（自動引き落としの場合は、手段ごとに別の期限が示されている）。
:::

2つの表は、そのまま横に並べて比べられない。BASEは費用の大半が「売れた額に対する率」で、カラーミーショップの有料プランは費用の大半が「月額」だ。税の書き方も違う。カラーミーショップの料金ページはすべて税込と注記しているが、後で見るとおり、フリープランの手数料についてはヘルプに「税抜」と書かれた箇所がある。BASEはグロースの月額を税込と書いているが、料金ページの手数料の率には税込か税抜かの表記が見当たらなかった。

## 売れたときに引かれるもの

:::fact
BASEのヘルプによれば、決済手数料は商品が売れた場合のみ、1注文ごとの合計金額（送料を含む）から差し引かれ、小数点以下は四捨五入される。料金ページの注記によれば、ショッピングアプリ「PAY ID」からの注文には、プランにかかわらず1注文あたり決済手数料3.6%+40円とサービス利用料5.9%がかかる。
:::

:::fact
カラーミーショップのヘルプセンターによれば、フリープランで使う決済は、有料プラン向けとは内容が異なる「フリープラン専用のカラーミーペイメント」（GMOイプシロンとの契約）だ。決済手数料は受注1件につき「6.6%＋30円（税抜）」、Amazon Payは6.5%+30円で、売上から相殺される。クレジットカードは任意で、使う場合は「3Dセキュア（本人確認サービス）」の契約が必須となり、月額1,000円（税抜）がかかる。フリープランのページは、表で決済手数料を「6.6% + 30円 ～」、よくある質問で「決済金額の6.6％＋33円」と書いている。
:::

:::fact
有料プランで使うカラーミーペイメントは、公式ページによればGMOイプシロンが提供する決済のパッケージで、料金はカラーミーショップ（GMOペパボ）ではなくGMOイプシロンに支払う。ページの表（税込・有料プラン契約時）では、クレジットカードがレギュラー3.4%、ラージ3.19%、プレミアム2.99%〜3.19%、Amazon Payが3.9%、PayPayが3.45%（レギュラーとラージは月額2,200円）、楽天ペイが4%（月額2,200円）だ。利用には審査があり、申し込みから利用開始まで約5〜24営業日程度かかる。利用条件は有料プランの申し込みまたは契約が済んでいることで、フリープランの利用者は対象外と書かれている。
:::

BASEでは、使う支払い方法が増えても、ショップが払う率は基本的に変わらない（PayPay、Amazon Pay、PayPalの1%を除く）。カラーミーショップの有料プランでは、支払い方法ごとに料率や月額が分かれていて、月額のかかる支払い方法を入れるほど固定費が積み上がる形だ。

## 使える支払い方法

| 支払い方法 | BASE（両プラン共通） | カラーミー フリー | カラーミー 有料プラン |
| --- | --- | --- | --- |
| クレジットカード | 使える | 使える（任意。3Dセキュア月額1,000円（税抜）が必須） | 使える |
| コンビニ払い | 使える（Pay-easyを含む） | 使える（セブン-イレブンは法人のみ） | 使える（165円〜/回。法人は月額最低手数料1,100円） |
| 銀行振込 | 使える | バーチャル口座のみ | 使える（バーチャル口座は月額1,100円 + 22円/回） |
| キャリア決済 | 使える | 一覧にない | 法人のみ（月額3,300円 + 6%） |
| 後払い | PAY ID あと払い | GMO後払い | GMO後払い（月額1,100円 + 4.0% + 279円/回） |
| 代金引換 | 使えない | 使えない | 使える（352円〜/回） |
| PayPay | 使える（+1%） | 一覧にない | 使える（3.45%。レギュラーとラージは月額2,200円） |
| Amazon Pay | 使える（+1%） | 使える（6.5% + 30円） | 使える（3.9%） |
| PayPal | 使える（+1%） | 一覧にない | 設定できる（PayPalとの契約） |
| 楽天ペイ | 一覧にない | 一覧にない | 使える（月額2,200円 + 4%） |

:::fact
BASEのヘルプによれば、BASEで使える支払い方法は「BASEかんたん決済」の8種類（クレジットカード、PAY ID あと払い、コンビニ（Pay-easy）、銀行振込、キャリア決済、Amazon Pay、PayPal、PayPay）だけで、すべてのショップでBASEかんたん決済の利用が必須だ。代引き、ショップ自身の銀行口座への直接の振り込み、現金手渡しは使えないと明記されている。利用申請をすれば、チェックを入れた決済方法は原則すぐに使える。個人の場合、クレジットカードのJCBとアメリカン・エキスプレスは申請から2〜3営業日後に使えるようになる。法人の場合は「法人利用申請」が必要で、審査には新規開設時でおよそ6営業日ほどかかる。購入者側には、コンビニ払いで360円（税込）、銀行振込で360円（税込）と金融機関の振込手数料、キャリア決済で300円（税込）、PAY ID あと払いのコンビニ支払いで350円（税込）の手数料がかかり、カード、Amazon Pay、PayPal、PayPayは手数料なしとされている。
:::

:::fact
カラーミーショップのヘルプセンターによれば、フリープランで使える支払い方法は、Amazon Pay、コンビニ払い、クレジットカード（5ブランド）、GMO後払い、銀行振込（バーチャル口座）で、通常の銀行振込、ゆうちょ振替、商品代引は使えない。有料プランでは、カラーミーペイメントのほか、商品代引、銀行振込、ゆうちょ振替や、ほかの決済代行会社（クロネコWebコレクト、ゼウス、NP後払い、PayPalなど）も設定できる一覧になっている。カラーミーペイメントのページは法人向けと個人向けの表を分けており、個人向けの表にスマートフォンキャリア決済の行はなく、個人契約ではクレジットカード決済とコンビニ決済が「必須」とされている。表の代引き（ゆうパックコレクト）は352円〜/回で、料金ページの比較表では代引き決済が396円〜と書かれている。
:::

## 売上金が手元に届くまで

:::fact
BASEのヘルプによれば、売上金は「振込申請」をして引き出す。申請から10営業日（土・日・祝を除く）でショップの指定口座に振り込まれ、申請ごとに振込手数料が一律250円、申請額が2万円未満なら事務手数料500円がかかる。振込申請は1日1回まで、売上残高が751円以上で申請でき、1回の上限は原則100万円。急ぐ場合は、申請額の1.5%で最短翌営業日の「お急ぎ振込」、3%で最短当日（土・日・祝を含む）の「最速振込」があり、どちらも振込手数料と事務手数料は別にかかる。この2つは初回の申請では使えず、一定の基準を満たしたショップに順に開放されるとされている。料金ページは、BASEカードを発行すれば売上金をすぐに使えると案内している。振込申請の期限は、注文を「対応済」にした月の末日を締め日として、締め月の6か月後の月末までで、期限を過ぎた売上は失効すると書かれている。
:::

:::fact
カラーミーペイメントのページによれば、有料プランの入金サイクルは当月末日締め・翌月末日入金で、すべての決済手段の売上をまとめて入金する。オプションの「早期入金サービス」（月額2,200円、手数料0.5%）を契約すると、当月末日締め・翌月15日入金になる。フリープラン専用のカラーミーペイメントも、ヘルプセンターによれば月末締め・翌月末入金だ。入金のときに振込手数料がかかるかどうかは、当サイトが確認したカラーミーショップの公式ページには書かれていなかった。
:::

BASEは、ショップが申請したときに、申請した額を引き出す仕組みだ。カラーミーショップは、月ごとにまとめて自動で入金される仕組みだ。前者は引き出す時期を選べる代わりに1回ごとの手数料と申請の期限があり、後者は申請の手間がない代わりに、月の初めに売れた分は、入金まで2か月近く空く。

## 月の費用を計算してみる（例示）

以下は、上の公式の数字だけを使った当サイトの計算で、実際の請求額ではない。前提は次のとおり。

- すべての注文が国内発行のカード（Visa/Mastercard）で支払われると仮定する。
- 1件あたりの固定額（BASEの40円、カラーミーショップ フリーの30円）があるので件数が要る。1件5,000円（送料込み）と仮定する。これは当サイトが置いた仮定で、公式の数字ではない。
- カラーミーショップ フリーは、カードを使うために必須とされる3Dセキュアの月額1,000円（税抜の表記のまま）を含める。
- 初期費用、アプリやオプションの料金、有料テンプレート、売上金の振込にかかる手数料は含めない。
- 料率は公式ページの数字をそのまま使う。税込・税抜の表記は上で見たとおりそろっておらず、同じ基準の金額ではない。カラーミーショップの「〜」付きの料率は下限を使う。

| プラン | 月商10万円（20件） | 月商50万円（100件） |
| --- | --- | --- |
| BASE スタンダード | 7,400円 | 37,000円 |
| BASE グロース（月払い） | 22,880円 | 34,480円 |
| BASE グロース（年払い） | 19,480円 | 31,080円 |
| カラーミー フリー | 8,200円 | 37,000円 |
| カラーミー レギュラー | 8,350円 | 21,950円 |
| カラーミー レギュラー（11月改定後） | 9,340円 | 22,940円 |

計算は次のとおり。

- BASE スタンダード: 100,000 × 3.6% + 40 × 20 + 100,000 × 3% = 3,600 + 800 + 3,000 = 7,400円。500,000 × 3.6% + 40 × 100 + 500,000 × 3% = 18,000 + 4,000 + 15,000 = 37,000円。
- BASE グロース（月払い）: 19,980 + 100,000 × 2.9% = 19,980 + 2,900 = 22,880円。19,980 + 500,000 × 2.9% = 19,980 + 14,500 = 34,480円。年払いは月額を16,580円に置き換え、19,480円と31,080円。
- カラーミー フリー: 100,000 × 6.6% + 30 × 20 + 1,000 = 6,600 + 600 + 1,000 = 8,200円。500,000 × 6.6% + 30 × 100 + 1,000 = 33,000 + 3,000 + 1,000 = 37,000円。1件33円で計算すると8,260円と37,300円になる。
- カラーミー レギュラー: 4,950 + 100,000 × 3.4% = 4,950 + 3,400 = 8,350円。4,950 + 500,000 × 3.4% = 4,950 + 17,000 = 21,950円。改定後は月額を5,940円に置き換え、9,340円と22,940円。

このほか、BASEで売上金を月に1回引き出すと、振込手数料250円が加わる（この例ではどの場合も申請額が2万円以上なので、事務手数料はかからない）。カラーミーショップ側の入金時の手数料は、上で書いたとおり確認できなかったので比べていない。BASEのヘルプは、グロースプランが得になる月商の目安を「約50万円」（PAY IDアプリからの注文を除く）としている。

:::guess
この例示の範囲では、月商10万円ではBASEのスタンダードとカラーミーショップのフリー、レギュラー（改定後を含む）が7,400〜9,340円に収まり、BASEのグロースは約1.9万〜2.3万円になる。月商50万円では、カラーミーショップのレギュラーが2万円台前半、BASEのグロースが3万円台、BASEのスタンダードとカラーミーショップのフリーがどちらも37,000円になる。売上が小さいうちは月額のないプランの費用が小さく、売上が大きくなるほど、月額を払って料率を下げるプランの費用が小さくなる。どの月商で入れ替わるかは、1件あたりの金額、カード以外の支払い方法の割合、使うアプリやオプションによって変わるとみられる。
:::

## プランの切り替え、サポート、デザイン、インボイス

### プランの切り替えと契約期間

:::fact
BASEのスタンダードとグロースはいつでも切り替えられ、グロースの契約期間は1か月か12か月だ。料金ページは、最短30秒で開設でき、ほぼすべての機能を無料で試せると案内している。カラーミーショップの有料プランは3・6・12か月の契約で、レギュラーとラージには30日間の無料体験がある。有料プランからフリープランへは戻れず、ラージからレギュラー、プレミアムからレギュラーやラージへの変更は契約更新のときにだけできる。
:::

### サポート

:::fact
BASEのヘルプによれば、電話によるサポート窓口はなく、問い合わせはお問い合わせフォームから受け付けている。カラーミーショップの料金ページによれば、有料プランにはメールサポート（返信の目安はレギュラーが2営業日以内、ラージが1営業日以内、プレミアムはECアドバイザーから1営業日以内）と、国内のみの電話サポートがある。フリープランのページは、フリープランのサポートを「カラーミーAIチャット」とメールとし、電話での案内は行っていないと書く。サポート一覧のページは、AIチャットに24時間いつでも相談できると案内している。
:::

### デザイン

:::fact
BASEのデザインページによれば、無料テンプレートは全22種類で、有料を含めた合計は100種類以上。有料テンプレートは月額料金のない買い取りで、デザインパーツの追加など一部のカスタマイズは使えない。HTMLの編集は「HTML編集 App」で行え、ヘルプは、このAppで編集したテーマにはBASEによる更新（新機能の追加や不具合の修正）が自動で適用されず、HTMLやデザインの技術的なサポートは行っていないと説明している。カラーミーショップの機能ページによれば、デザインテンプレートは無料・有料あわせて約90種類で、HTML/CSS編集にも対応する。フリープランのページの比較表にもHTML・CSS編集の行がある。
:::

### インボイス（適格請求書）

:::fact
BASEのヘルプによれば、ショップは設定画面で購入者へインボイスを発行するかどうかを選べ、設定すると対象の注文についてインボイスがメールで送られる。登録番号はショップ自身のものを登録し、BASEの登録番号は使えない。インボイス制度に対応した請求書・納品書は現在発行できないと書かれている。同じページによれば、BASEがショップに発行するインボイスの対象は振込手数料、事務手数料、お急ぎ振込・最速振込の手数料、グロースプランの月額などで、BASEかんたん決済手数料とサービス利用料はインボイスの発行がない区分に入っている。カラーミーショップの機能ページによれば、請求書・納品書・領収書の発行と印刷は全プランで無料（フリープランは一括印刷に非対応）で、公式の機能一覧には、適格請求書を含む書類を購入者側で自動発行できるアプリ「インボイスくだサイ for カラーミーショップ」が月額1,100円からとして載っている。
:::

カラーミーショップの標準の領収書・請求書が、登録番号など適格請求書の記載事項を満たすかどうかは、機能ページからは読み取れなかった。法人の客や経費で買う客が多いショップや、手数料の仕入税額控除を考える課税事業者は、申し込む前に両社へ確かめたほうがよい。

## 技術構成の重なり

上の機械比較では、両記事の技術構成で共有されるのはPHPとAmazon CloudFrontの2つだ。PHPは、どちらもショップの中核のアプリケーションについて公式の技術ブログで確認できたものだ。CloudFrontは、どちらも紹介用のサイトを当サイトが観測した結果（likely）で、ショップ本体の配信構成とは別の可能性がある。BASEの「AWS」と、カラーミーショップの「Amazon RDS for MySQL」「Amazon S3」「AWS Direct Connect」は機械比較では別の項目として数えられるが、2社ともAWSのサービスを使っている点では重なっている。違いは置き方で、BASEはAWSとAmazon Auroraの上で動いていると公式ブログに書いており、カラーミーショップはアプリケーションを動かすVMとKubernetesのノードを自社のOpenStackのプライベートクラウドに置き、マスターDBをAmazon RDSに置くハイブリッド構成だと公式ブログに書いている。こうした構成の違いが、ショップが払う料金に直接表れるわけではない。

## なぜ、こう分かれるのか

:::guess
違いの根は、2社が何で収益を得ているかにあるとみられる。[BASEの解剖記事](/ja/articles/base)で見たように、BASEの収益の中心はショップの売上に比例する手数料で、決算資料は、テイクレート（売上高を決済額ベースのGMVで割った比率）の上昇を、売上高の伸びがGMVの伸びを上回った理由に挙げている。売れた代金がBASEかんたん決済を通り、BASEから振り込まれる仕組みは、取引の額に応じて収益を得る設計と整合する。売上ゼロの月に費用ゼロでいられるのも、売れた月に取る設計だからと推測される。
:::

:::guess
[カラーミーショップの解剖記事](/ja/articles/colorme-shop)で見たように、カラーミーショップの収益の柱は月額利用料で、販売手数料は0円、決済の手数料はGMOイプシロンに支払う形になっている。料金表に支払い方法ごとの月額や料率が並ぶのは、決済を自社ではなく決済代行会社との契約として切り出しているためとみられる。売上が大きくなるほど月額の比重が小さくなる設計は、上位プランへ移る店舗を増やして単価を上げてきた同社の数字とも整合する。どちらが良い悪いではなく、何で収益を得るかが、料金表と入金の形を決めていると推測される。
:::

:::pull
BASEは売れた分から引き、申請に応じて振り込む。カラーミーショップは月額を先に受け取り、決済は別の会社との契約に任せて、月ごとにまとめて入金する。「無料」の中身より先に、お金の通り道が違う。
:::

## 状況別の当てはまり

順位はつけない。上で確認した事実から、どの状況がどちらの設計に合いやすいかを整理する。

:::guess
BASEの設計に合いやすいとみられるのは、次のような場合だ。

- 売れるかどうか分からず、売れない月の費用を0円にしたい。スタンダードは初期費用も月額も0円で、費用は売れたときの手数料と、引き出すときの振込手数料だ。上の例示では、月商10万円のときスタンダードの費用が表の中でいちばん小さい。
- 個人で始めて、カード以外の支払い方法もまとめて使いたい。BASEかんたん決済は申請すれば原則すぐに使え、個人でもキャリア決済を使える。ただし、コンビニ払いや銀行振込では購入者側に手数料がかかる。
- 売上金を引き出す時期を自分で決めたい。手数料を払えば最短翌営業日や当日の振込も選べる（使えるショップには条件がある）。
- 売上の増減に合わせてプランを月単位で切り替えたい。

カラーミーショップの設計に合いやすいとみられるのは、次のような場合だ。

- 月商がある程度見込めて、月額を払ってでも1件ごとの料率を下げたい。上の例示では、月商50万円のときレギュラーの費用が表の中でいちばん小さい。
- 代金引換や、購入者がショップの口座に直接振り込む銀行振込を使いたい。どちらもBASEでは使えず、カラーミーショップの有料プランでは設定できる。
- 電話で日本語の問い合わせをしたい。有料プランには電話サポートがある。
- 売上金を申請なしで月ごとにまとめて受け取りたい。入金までの期間はBASEの通常の振込より長くなる。
:::

カラーミーショップのフリープランは、月額0円という点ではBASEのスタンダードと同じ側にあるが、カードを使うと3Dセキュアの月額1,000円（税抜）がかかり、使える支払い方法も限られる。フリープランからレギュラー以上へ移ると、フリープランへは戻れない。始める前に、このプランで使える支払い方法と、移ったあとの固定費を確かめておく必要がある。BASEのスタンダードも、売上金を引き出すたびに250円がかかり、申請額が2万円未満なら500円が加わる。申請の期限を過ぎた売上は失効するので、引き出す頻度と期限を見込んでおく必要がある。

## 乗り換えを考える場面

:::guess
BASEから移ることを考えるきっかけになりそうなのは、月商が伸びてサービス利用料と決済手数料の合計が重くなったとき、代金引換や電話サポートが必要になったときだと推測される。ただし、BASEの中でもグロースへ切り替えれば料率は下がるので、まずはプランの切り替えと比べることになるとみられる。カラーミーショップから移ることを考えるきっかけになりそうなのは、売上が落ちて有料プランの月額が重くなったとき（フリープランへは戻れない）、2026年11月の改定でレギュラーやラージの月額が上がったあとに費用を見直すときだとみられる。どちらの方向でも、商品データ、デザイン、URLの移し替えという作業がともなうが、その手間は当サイトは確認していない。
:::

どちらにも月額0円のプランがある。違うのは、売れたお金が誰の決済を通り、いつ、何を引かれて手元に届くかだ。自分の月商の見込みと、客がどう支払うかを先に決めると、料金表の読み方が決まる。
