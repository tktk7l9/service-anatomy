[Cursor](/ja/articles/cursor)と[GitHub Copilot](/ja/articles/github-copilot)は、同じ棚に並べて比べられることが多い。ただし2026年に入って、両方の料金表が別の形へ作り変えられた。Copilotは6月に、リクエスト数からトークンへ課金の単位を移した。Cursorは10月に、新規の顧客にはGrokとXと同じ購読を販売する形になった。この記事は、両社の公式ページを2026年11月2日に読み、書かれている数字と条件を並べる。当サイトは両製品を長期間使い込んだ体験を書いているのではなく、公開されている料金表とドキュメントを突き合わせている。料金はこの数か月で大きく動いているので、契約の前に必ず公式ページを確認してほしい。

## 料金を並べる

:::fact
以下は、Cursorの料金ページとドキュメント、Copilotのドキュメント（いずれも2026-11-02閲覧）の内容を、当サイトが場面ごとに並べ直したものだ。価格はどちらも米ドルで、Cursorは税別と明記している。

| 項目 | Cursor（X Subscription） | GitHub Copilot |
| --- | --- | --- |
| 無料 | Free（Agent・Chatは制限付き） | Free（補完月2,000回、チャットとエージェントは自動選択の枠内） |
| 入門 | Plus 月8ドル（自社枠のモデルのみ、Cloud Agentsなし） | Pro 月10ドル（クレジット1,500） |
| 中位 | Premium 月30ドル（Plusの4倍） | Pro+ 月39ドル（クレジット7,000） |
| 高頻度 | Super 月100ドル（Plusの15倍）、Ultra 月200ドル（Plusの50倍） | Max 月100ドル（クレジット20,000） |
| チーム | 1席 月30・100・200ドル | Business 1席 月19ドル、Enterprise 1席 月39ドル |
| 枠の単位 | 週次の共有プール。Grokの利用と同じ枠 | 月次のクレジット。未使用分は繰り越さない |
| 枠に含まれるもの | Grok 4.7・4.6・4.5とComposer 2.5 | プランで使える全モデルをトークン単価で消費 |
| 他社モデル | 枠に含まれない。Premium以上でAPI価格、前払いクレジットから | クレジットの枠内で消費。超過分は予算を設定して追加 |
| 枠が尽きたら | 待つ、前払いクレジット、アップグレード | 待つ、追加の予算、差額でアップグレード |
| 法人の上乗せ | 対象の他社モデルに100万トークンあたり0.25ドル（Cursor Token Rate） | 上乗せの記載なし。クレジットは組織でプール |
| 補完 | Tabの扱いは下記 | 補完とNext Editはクレジットの外で、有料プランは無制限 |

年払いはCursorがPlus 80ドル、Premium 300ドル、Super 1,000ドル、Ultra 2,000ドルと案内している。Cursorの旧プラン（Hobby、Pro 月20ドル、Pro+ 月60ドル、Ultra 月200ドル、Teams Standard 1人月40ドル、Teams Premium 1人月120ドル）は既存の顧客には続くが、新規の顧客はX Subscriptionから始まる。旧プランのProなどには無制限のTabが含まれると書かれている。当サイトが読んだX Subscription側の案内には、Tabの扱いの明記を確認できなかった。

Copilotは法人のプランを、クレジットの価格に含める形で据え置き、Copilot accessでは席料0ドルまたは10ドルでトークンを最初から課金する形も用意している。消費税については、GitHubは2024年10月から、カードまたはPayPalで支払う日本のセルフサービス顧客に10%の消費税を課すと案内している。
:::

:::fact
同じモデルの単価を比べると、公開価格は一致している。CursorのModels & PricingとCopilotのModels and pricing（2026-11-02閲覧）の100万トークンあたりの米ドルを並べる。

| モデル | Cursor 入力／キャッシュ／出力 | Copilot 入力／キャッシュ／出力 |
| --- | --- | --- |
| Claude Opus 5.5 | 4／0.2／20 | 4／0.20／20 |
| Claude Fable 5.1 | 10／0.25／50 | 10／0.25／50 |
| Grok 4.7（標準のコンテキスト） | 2／0.5／6 | 2／0.50／6 |
| Composer 2.5 | 0.5／0.2／2.5 | 提供なし |
| MAI-Code-1.1-Flash | 掲載なし | 0.20／0.02／1.20 |

Cursorの自社枠のモデルの単価は、週次の枠を超えた場合に適用される。枠の内側では、モデルごとに異なる速度で枠を消費すると説明されている。
:::

:::guess
同じAPI単価で買えるのであれば、両者の値段の差はトークンの単価ではなく、月額で何がついてくるかに表れるとみられる。Claude中心で使いたい人にとって、Copilotは月39ドルのPro+に70ドル分のクレジットが付くのに対し、Cursorは月30ドルの枠に他社モデルが入らず、前払いクレジットから別に払う。この比較だけならCopilotに分がある。一方、Grok 4.7やComposer 2.5を主に使うなら、Cursorの週次の枠がそのまま効き、量の面では旧プランの2倍以上とCursorは説明している。どちらが安いかは、使うモデルの比率でほぼ決まると考えられる。フレックス枠は可変とされているので、この差がいつまで続くかは保証されない。
:::

:::pull
単価が同じになったとき、料金の差はトークンではなく、月額の枠に誰のモデルが入っているかに移る。
:::

## モデルの選び方とルーティング

:::fact
Cursorのドキュメントによれば、Autoには費用重視のCost、バランスのBalance、知能重視のIntelligenceの3つがあり、個人プランはCostだけを持つ。Costは、どのモデルが応答しても自社枠のリクエストとして週次の枠から差し引かれる。TeamsとEnterpriseのCursor Routerは他社モデルも選ぶことがあり、その場合は前払いクレジットで支払う。

CopilotのFusionは、Single・Cascade・Critiqueの実行パターンをプロンプトごとに選び、StandardとHighとMaxの努力量を選べる。HighとMaxはPro+以上である。使ったモデルごとの標準料金を払い、2026年11月30日までは有料プランに30%の割引がある。Free・Studentは自動選択のみで、モデルは自分で選べない。Copilotのモデルの範囲はプランによって異なり、Claude Opus 5.5やGPT-5.6 SolはPro+以上である。
:::

:::fact
Cursor側では、OpenAIとの関係が動いている。CNBC（2026年8月29日）によれば、OpenAIは買収後にCursor経由の自社モデルの提供を終えると発表し、終了日として2026年11月12日を提案した。CursorのCEOは、OpenAIのモデルは利用トラフィックの約5%で、解決に向けて協議中だと述べた。2026年11月2日時点のCursorのドキュメントには、GPT-5.6系を含むOpenAIのモデルが引き続き掲載されており、旧世代のモデルの多くは既定で非表示とされている。当サイトはこの提案日以降どうなるかを確認できていない。

Copilotのプラン比較ページには、Anthropic、OpenAI、Microsoft、Google、xAI、Moonshotのモデルが並ぶ。Copilotの他社モデルにおける学習の扱いやホスティングは、公式のホスティングページに提供元ごとに書かれている。
:::

## エージェントとレビュー

:::fact
両社ともクラウド上でタスクを実行し、プルリクエストを返すエージェントを持つ。

| 項目 | Cursor Cloud Agents | Copilotのクラウドエージェント |
| --- | --- | --- |
| 利用できるプラン | Premium以上、Teams、Enterprise、旧有料プラン | Pro以上（Business・Enterpriseはポリシー次第） |
| 実行環境 | 隔離されたVM。スナップショットやDockerfileで環境を構成 | GitHub Actions、またはクラウドサンドボックス |
| 対応する置き場所 | GitHub、GitLab、Azure DevOps Services、Bitbucket Cloud | GitHubのみ |
| 複数リポジトリ | 変更した各リポジトリにPRを開ける | サンドボックスは組織内の複数リポジトリのセッションに対応。1タスクのPRは1本 |
| 時間の上限 | 当サイトが読んだ範囲に記載なし | Actionsは59分で延長不可 |
| 費用 | プランの枠を消費 | AIクレジットに加えて、Actionsまたはサンドボックスの計測 |
| 他社のエージェント | 掲載なし | ClaudeとCodexを公開プレビューで提供 |

コードレビューは、CursorではBugbotがPremium以上のプランに含まれ、CopilotではPro以上で使える。Copilotのレビューは、既定のBalancedで1回平均約1.5ドルが目安とされ、Actionsの分数が別途かかる。

Cursorはさらに、自社のGitホスティングOriginをアーリーベータで提供している。リポジトリの作成、GitHubからのミラー、プルリクエストの作成・レビュー・マージができるとされる。Copilotは逆に、GitHub以外のリポジトリには対応しないと明記している。
:::

:::guess
エージェントの比較で実際に効くのは、どこにコードを置いているかだとみられる。GitLabやBitbucketの利用者にとって、Copilotのクラウドエージェントは選択肢にならず、Cursorが先に候補に上がる。GitHubに置いている組織では、Copilotの権限・監査・Actionsの設定をそのまま使えることが強みになると考えられる。他社のエージェントを同じ画面で扱える点も、モデルの好みが割れるチームには意味があるだろう。一方でCursorのOriginは、エージェントの作業場所そのものを自社に寄せる試みとも読めるが、現時点ではアーリーベータである。
:::

## データと学習

:::fact
データの学習の扱いは、既定の設定と法人の扱いで整理できる。

| 項目 | Cursor | GitHub Copilot |
| --- | --- | --- |
| 個人の学習の設定 | Privacy Modeをオンにすると、Cursorは顧客データを学習に使わない。オフならコードベースデータやプロンプトなどを保存・学習に使う場合がある | Free・Pro・Pro+・Maxは、2026年4月24日からインタラクションデータを学習に使う場合がある。設定でDisabledにできる |
| 法人の既定 | Teamsは全メンバーで既定オン。Enterpriseも既定オン。管理者が強制できる | BusinessとEnterpriseの顧客データは学習に使わない |
| 第三者への送信 | Privacy Mode時は全提供元とゼロデータ保持の契約 | 提供元ごとの契約。第三者のモデル提供者には学習用データを共有しない |
| 例外 | ゼロデータ保持外のモデルは表示または管理者の許可が必要 | Claude Fable系はゼロデータ保持の既定の対象外。Student・無料の教員・有料組織のメンバーは学習の対象外 |

Cursorのヘルプは個人向けPrivacy Modeの既定を明記していない。CursorのPrivacy Modeは、Grok Botのような別の製品の扱いには及ばないとヘルプは説明している。
:::

:::guess
どちらの製品も、法人向けには「学習しない」を明確に打ち出し、個人向けには設定の確認を求める形に揃っている。個人のアカウントで業務のコードを扱う人は、CursorならPrivacy Mode、Copilotなら学習の設定を、契約の最初に確認するのが安全だと考えられる。X Subscriptionに移ると、Grok側の製品との関係も確認の範囲に入ると推測される。
:::

## どんな開発者にどちらが合いやすいか

ここからは、上の表を当サイトが読んだうえでの整理だ。優劣を付けるものではなく、使い方ごとに、どの行が効いてくるかを示す。

:::guess
- GitHubにコードを置き、ClaudeやGPTを主に使う個人は、Copilotの料金表が当てはまりやすいとみられる。Pro+は月39ドルで70ドル分のクレジットがあり、Opus 5.5も枠の中で消費できる。Visual Studio、JetBrains IDE、Eclipse、Xcodeでも使える。
- 補完中心で、エージェントはたまにしか使わない人は、Copilot Proの月10ドルが手頃と考えられる。補完はクレジットを消費しない。
- Grok 4.7やComposer 2.5を中心に、エディタの中でエージェントを動かしたい人は、Cursorの枠が効きやすいとみられる。Xの特典やGrokの製品を使う人なら、まとめる利点もある。ただしPlusにCloud Agentsは含まれず、Premium以上が必要になる。
- GitLab、Bitbucket、Azure DevOpsにコードを置くチームは、Cursor Cloud Agentsの対応範囲が決め手になりやすい。
- 既にGitHub Enterpriseを使う組織は、Copilotの席料とプール型のクレジット、ポリシー、監査ログの一体運用が利点になりそうだ。チームの席料だけを見ても、Business月19ドルはCursorのTeams最小の月30ドルを下回る。ただし枠の中身が違うので、席料だけの比較では判断できない。
- OpenAIのモデルに依存する業務があるCursor利用者は、2026年11月12日の提案日の扱いを確認してから判断したほうがよいと考えられる。
- 既存のCursorの旧プラン利用者は、切り替えが任意で、切り替えると戻れないとされている点に注意が必要だ。
:::

## なぜ料金表の形が違うのか

:::fact
[Cursorの解剖記事](/ja/articles/cursor)のとおり、CursorはVS Codeのコードベースを土台にしたエディタとして始まり、公式ブログの一覧によれば2026年8月14日にSpaceXの傘下に入ったと発表した。現在の料金ページは、購読の販売元をX Subscription Corpと記している。[Copilotの解剖記事](/ja/articles/github-copilot)のとおり、CopilotはGitHubの補完機能として始まり、GitHub自体は2018年にMicrosoftが買収を発表した。4月のブログは、プレミアムリクエストのモデルは持続できないとして従量課金へ移った理由を説明し、Microsoftの決算説明会（2026年7月29日）は、6月の変更後に利益率が四半期の中で改善したと述べた。
:::

:::guess
料金表の形の違いは、それぞれの会社が何を持っているかから来ているとみられる。Cursorの親会社はGPUとGrokを持つ。だから料金の中心は自社モデルの枠になり、他社モデルは枠の外でAPI価格になると考えられる。利用者を自社モデルへ寄せるほど、原価はグループの内側に収まる。枠が週次なのも、計算資源を平らに使う設計と読める。

GitHubの親会社はAzureと、独占ではないモデル群を持つ。GitHubが持つ最大の資産は、モデルではなくリポジトリとプルリクエストの場所だ。だからCopilotの料金は全モデルを1つのクレジットで買える形になり、Fusionと自社の軽量モデルで費用を下げ、他社のエージェントも自分の場所へ招き入れていると推測される。

もちろん両社は相手の領域に踏み込んでいる。CursorはOriginでGitホスティングへ、CopilotはCopilotアプリやCLIで手元の作業へ広がる。それでも料金表は、親会社が何で稼ぎたいかを映している。
:::

CursorとCopilotは、同じモデルを同じ単価で売りながら、別のものを月額で束ねている。Cursorは自社モデルと、エディタの中の体験と、X全体の購読を束ねる。CopilotはAPI単価のクレジットと、GitHubの中の仕事の流れを束ねる。選ぶ側が見るべきなのは、どちらのベンチマークが高いかより、自分がどのモデルを主に使い、コードをどこに置き、誰のデータの条件で働いているかだ。その3つが決まれば、2つの料金表のどの行を読めばよいかはおのずと決まる。
