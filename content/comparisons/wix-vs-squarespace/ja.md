[Wix](/ja/articles/wix)と[Squarespace](/ja/articles/squarespace)は、テンプレートを選んでドラッグ&ドロップで直すだけでサイトを公開できるサイトビルダーとして、並べて比べられることが多い。Wixは2006年に創業してテルアビブに本社を置き、予約や決済までを積み上げた「何でもできる」作りで、Squarespaceは2003年に大学の寮で生まれ、デザインの出来で選ばれてきた。2本の解剖記事を重ねると、2026年の2社の違いは機能の数ではなく、AIの時代にどこで稼ぐかに出ている。

この記事は、両社の公式の料金ページ、ヘルプセンター、決算資料、ニュースルーム、エンジニアリングブログ、Google Cloudの導入事例を2026年10月7日に読み直してまとめた。当サイトは両方で同じサイトを作って使いやすさや表示の速さを測ってはおらず、デザインの好みや体感の優劣は扱わない。

## 規模：決算を出す会社と、出さなくなった会社

Wixはナスダック上場で、四半期ごとに決算を出す。Squarespaceは2024年に非上場になり、業績の数字を公開の決算資料から追えなくなった。

:::fact
Wixの2026年8月4日の決算発表によれば、2026年4〜6月期の売上は5億6,310万ドル（前年同期比+15%）、期末のARRは19億6,300万ドル（同+15%）で、株主向けの資料によれば登録ユーザーは約3億1,700万人、従業員は6月上旬の組織の再編を経て4,371人だった。投資会社Permiraの発表（2024-10-17）によれば、Squarespaceは同社のファンドが総額約72億ドルの全額現金で買収を終え、ニューヨーク証券取引所の上場を外れた。Squarespaceの会社紹介ページは社員を1,760人超、開設以来作られたWebサイトを数百万とし、Google Cloudの導入事例は、200を超える国と地域の数百万の顧客に使われていると書く。
:::

| 項目 | Wix | Squarespace |
| --- | --- | --- |
| 創業 | 2006年 | 2003年 |
| 資本 | ナスダック上場（WIX） | 2024年10月にPermiraが約72億ドルで買収、非上場 |
| 公表している規模 | 2026年4〜6月期の売上5億6,310万ドル、ARR19億6,300万ドル | 業績の開示なし、開設以来数百万のサイト |
| 利用者 | 登録ユーザー約3億1,700万人 | 200超の国と地域の数百万の顧客 |
| 社員 | 4,371人（2026年6月末） | 1,760人超 |

:::pull
Wixは無料で入口を広げ、AIでアプリまで作らせる。Squarespaceは無料の入口を持たず、ドメインとお金の流れで客を深く囲う。
:::

## 値段の付け方：無料で始めるか、試してから払うか

どちらも有料プランは4段階だが、入口の作り方が違う。

:::fact
Wixの料金ページ（2026-10-07確認）は、無料でサイトを作り、準備ができたらプランを選べると書き、クレジットカードの要らない無料プランと、Light・Core・Business・Business Eliteの4つの有料プランを並べる。価格と通貨は地域で変わり、表示は年払いの価格で、すべてのプランに14日間の返金保証が付く。当サイトの閲覧環境では、表示価格が年払いの初回の期間に限るオファーと注記されていたため、この記事ではWixの金額を並べない。Squarespaceの料金ページ（同日確認・日本からの表示）は、ベーシックが年払いで月額換算1,180円、コアが2,080円、アドバンスが3,040円で、無料プランはなく、すべてのサイトがクレジットカードなしの14日間の無料トライアルから始まる。ヘルプセンターによれば、Squarespaceの現行のプランはベーシック・コア・プラス・アドバンスの4つで、オンラインストアの取引手数料はベーシックだけ2%、デジタル商品の取引手数料はベーシック7%からアドバンス0%まで、上のプランほど下がる。
:::

| 項目 | Wix | Squarespace |
| --- | --- | --- |
| 無料プラン | あり（クレジットカード不要） | なし |
| 試し方 | 無料プランのまま作る、有料プランは14日間の返金保証 | 14日間の無料トライアル（クレジットカード不要） |
| 有料プラン | Light・Core・Business・Business Elite | ベーシック・コア・プラス・アドバンス |
| 価格の決まり方 | 地域で価格と通貨が変わる、年払いの価格を表示 | 請求先の国ごと（日本からは円建て） |
| 売上にかかる手数料 | 料金ページに取引手数料の記載なし | ベーシックのストア2%、デジタル商品7〜0% |

:::guess
Wixは無料プランで登録ユーザーの数を広げ、その中から有料に変わる人を増やす形で、3億を超える登録ユーザーという規模はこの入口の広さとみられる。Squarespaceは無料の入口を持たず、14日間で払うかどうかを決めてもらう形で、最初から事業に使う人に絞っているとみられる。前者は「まず作ってもらう」値付け、後者は「払う人だけを相手にする」値付けと読める。
:::

## AI：自社のモデルを作る側と、使った分をクレジットで払わせる側

:::fact
Wixは2026年1月21日に、自然言語で指示するAIエージェントとビジュアル編集を組み合わせたAIサイトビルダーWix Harmonyを発表した。2026年8月4日の決算発表で、CEOのAvishai Abrahami氏は、AIでアプリを作るBase44の自社LLM「Base 1」の投入と、年初のWix Harmonyの自社モデルの公開に触れ、株主向けの資料はBase 1を6月下旬に出したと書く。決算説明のスライドによれば、Base44のARRは2026年5月上旬に1億5,000万ドルに達し、会社は、年初にほぼゼロだったBase44の非GAAPの売上総利益率が下半期に約60%になると見込む。Squarespaceのヘルプセンターによれば、SquarespaceのAI機能はAIクレジットを使い、ベーシックは最初の10クレジットだけ、コアは毎月20、アドバンスは毎月120（料金ページの表示）が付き、ChatGPTやGeminiのような大規模言語モデルへのプロンプトに使われる。2026年7月に出した「AI Visibility」は、自分の店がAI検索でどう答えられているかを追う道具で、英語のアカウントに限られる。Refresh 2025では、業種に合わせて中身まで埋まったテンプレートを作るBlueprint AIの拡張や、ChatGPTのストアから使えるSquarespace GPTを出した。
:::

| 項目 | Wix | Squarespace |
| --- | --- | --- |
| AIの主な製品 | Wix Harmony（サイト）、Base44（アプリ） | Blueprint AI、Beacon AI、AI Visibility |
| モデル | Harmonyの自社モデル、Base44の自社LLM「Base 1」 | ChatGPTやGeminiなどのモデルにプロンプトを送る |
| 使用量の扱い | 決算で、推論の費用を自社モデルで下げると説明 | AIクレジット（ベーシックは初回10のみ、コア月20、アドバンス月120、追加はパック） |
| AIで生まれた事業 | Base44のARR1億5,000万ドル（2026年5月） | AI検索での見え方を測る道具 |

:::guess
WixはAIを、サイトの次の売り物である「アプリを作る道具」そのものにし、推論の費用を自社のモデルで抑えにいく側に立ったとみられる。SquarespaceはAIを、既存のサイトの利用者に向けた道具にとどめ、外部のモデルの費用をクレジットで利用者に分けて負担してもらう側とみられる。前者はAIで新しい客と売上を作りにいく賭け、後者はAIの費用を値段の中に閉じ込める守りと読める。
:::

## お金の流れとドメイン

:::fact
Wixの決算発表によれば、2026年4〜6月期のBusiness Solutionsの売上は1億6,470万ドル（前年同期比+14%）で、そのうち主にWix Paymentsによる取引収益は7,150万ドル（同+12%）、決算説明のスライドによれば決済の取扱高は36億ドル（同+3%）。スライドは、Creative SubscriptionsのARRにドメイン登録の収入を含めると定義している。Squarespaceは、Squarespace Capitalの発表（2025-08-26）によれば2023年に自社決済のSquarespace Paymentsを始め、その上にStripeが支える融資のSquarespace Capitalを重ね、Refresh 2025で金融口座のSquarespace Balanceや即日の出金を並べた。ただしヘルプセンターが示すSquarespace Paymentsの対象国に日本は入っていない。ドメインでは、Squarespaceは2024年11月にGoogle Domainsから数百万件のドメインの移管を終え、2026年2月のスーパーボウルLXでは、ドメインを取れずに苦しむエマ・ストーン氏のCMを流した。Wixの第2四半期の発表も、上半期にスーパーボウルへの投資があったと書いている。
:::

:::guess
Wixは決済の取扱高が伸び悩むなかでも、サイトの月額料金に加えて決済と制作会社経由の売上を太らせる形で、「商売そのものに乗る仕組み」を広げているとみられる。Squarespaceはドメインを入口に、サイト、メール、決済、融資へと深く入ってもらう形で、1人の顧客から長く稼ぐ設計とみられる。同じ年のスーパーボウルに両社が広告を出したのは、AIでサイトが簡単に作れるようになるほど、ブランドの名前で選ばれることの値打ちが上がっているからと推測される。
:::

## 紹介の仕組み

:::fact
Wixは、紹介経由の新規ユーザーがプレミアム契約に至ると報酬を払うWix Affiliate ProgramをImpactで運営し、決算では制作会社やフリーランス、LegalZoomやVistaprintのような再販パートナーを経由した売上を開示している。2026年4〜6月期のパートナー経由の売上は2億1,380万ドル（前年同期比+17%）だったが、会社は6月の見通しの修正で、パートナー経由の弱さがブッキングに響くと説明した。Squarespaceのヘルプセンターによれば、Impactで運営するSquarespace Affiliate Programは、初めての顧客がWebサイトのプランを契約すると1件100〜200ドルを払い、制作会社やフリーランス向けのCircleの参加者は、リンクを使わずに紹介料を受け取れる。
:::

## 技術構成の重なりは、Google Cloud・Apache Kafka・Fastlyの3件

このページの下に出る技術構成の比較は、2本の記事のtechStackを機械的に突き合わせたものだ。共通と判定されたのはGoogle Cloud、Apache Kafka、Fastlyの3件で、使い方はかなり違う。Wixの公式のSite Reliabilityのページは、自社のデータセンターに加えてGoogle Cloud、AWS、Fastlyの上でサイトを動かし、1社が落ちても自動で迂回すると書く。複数のクラウドに分散して、どこか1社の障害を乗り切る設計だ。Squarespaceは、Google Cloudの導入事例によれば、自社のデータセンターからGoogle Cloudへ移っている途中で、ドメインのDNSにもGoogle Cloud DNSを使い、Google Workspaceを売る。1社のクラウドに寄せ、そのマネージドなサービスを使い倒す方向だ。Apache Kafkaも、Wixでは4,000を超えるマイクロサービスをつなぐ非同期通信の背骨で、Confluentのクラウドに移したうえでプッシュ型のプロキシで費用を30%削った。Squarespaceでは、PostgreSQLからCockroachDBへデータベースを止めずに移すために、Debeziumで取り出した変更を流す管として使った。Fastlyは、Wixでは公式のページがCDNに使うと明記し、Squarespaceでは当サイトが応答ヘッダから推定した段階だ。

選ぶ側の問いは2つに分けられる。お金をかけずに作り始めたい、AIに話しかけてサイトやアプリまで作りたいなら、無料プランとHarmony、Base44を持つWixが向く。デザインの出来を最優先にし、ドメインから決済までを1つの会社にまとめたいなら、Squarespaceが向く。ただし日本の事業者にとっては、Squarespace Paymentsが使えず、AI Visibilityも英語のアカウントに限られる点を差し引く必要がある。どちらを選んでも、2026年のサイトビルダーは、サイトを作る道具から、AIと決済の上で商売を回す場所へと変わりつつある。
