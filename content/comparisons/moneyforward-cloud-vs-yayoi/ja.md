[マネーフォワード クラウド](/ja/articles/moneyforward-cloud)と[弥生](/ja/articles/yayoi)は、個人事業主やフリーランスが確定申告ソフトを選ぶときに並べて検討されることが多い。この記事は、2026年10月1日に両社の公式ページを確かめ、料金と機能の違いを整理したうえで、料金表の作りがなぜ分かれるのかを読む。当サイトは製品を実際に契約して試したわけではなく、根拠はすべて公開されている公式情報だ。料金やキャンペーンは変わるので、申し込む前に公式ページで最新の内容を確かめてほしい。

## 料金を比較する — 初年度と2年目以降

:::fact
マネーフォワード クラウド確定申告の料金ページによれば、個人向けは3プランで、表示価格はすべて税抜。同社の告知によれば、2026年12月1日に個人事業主向け有償契約の基本料金が改定され、同日時点で契約中の場合は、12月1日以降に更新となる契約から改定後の料金になる。

| プラン | 年払い（現在） | 年払い（2026年12月1日〜） | 月払い（現在 → 改定後） |
| --- | --- | --- | --- |
| パーソナルミニ | 10,800円/年 | 10,800円/年（変更なし） | 1,280円 → 1,680円 |
| パーソナル | 15,360円/年 | 22,560円/年 | 1,680円 → 2,880円 |
| パーソナルプラス | 35,760円/年 | 38,160円/年 | 年払いのみ |

1ヶ月の無料トライアルがあり、料金ページは「有料のプランへの自動移行はありません」としている。クレジットカードなしで試せるとも書かれている。有料プランの決済はクレジットカードのみで、銀行引落や請求書払いは使えない。告知には、月払いのみの「パーソナルミニ アプリプラン」（税込1,500円 → 1,880円）も載っている。
:::

:::fact
弥生の料金ページによれば、やよいの青色申告 オンラインは3プランで、価格は「+税」と表記されている（税抜）。機能は3プランとも同じで、違いはサポートの範囲だけだ。

| プラン | 初年度 | 次年度以降 |
| --- | --- | --- |
| セルフ | 無料 | 年額11,800円+税 |
| ベーシック | 無料 | 年額22,800円+税 |
| トータル | 年額19,800円+税 | 年額39,600円+税 |

初年度の価格は「初年度無償キャンペーン」によるもので、2027年3月15日までの申し込み分が対象、適用は1事業者につき1回。料金ページは、キャンペーンは予告なく変更・終了する場合があるとも書いている。使うには、自動更新の決済方法として口座振替かクレジットカードの登録が必要になる。更新の前に案内メールが届き、契約終了月の前月末日までキャンセルできる。別に、決算・申告機能を除いて最大2か月試せる無料体験プランもある。
:::

:::fact
やよいの白色申告 オンラインの料金ページによれば、フリープランは「すべての機能がずっと無料」で、サポートはWebFAQのみ。ベーシックプランは初年度無料で、無料期間終了後は年額11,500円+税。トータルプランは初年度が年額10,500円+税、次年度以降は年額21,000円+税。初年度の価格は同じく2027年3月15日までの申し込み分が対象で、決済方法の登録が必要になる。
:::

:::pull
消費税申告までできる最安プランの年額（税抜）は、弥生のセルフが11,800円（初年度は無料）、マネーフォワードのパーソナルが15,360円で、2026年12月1日からは22,560円になる。
:::

弥生の初年度は、キャンペーンの条件を満たす場合の価格だ。2年目からは通常の年額がかかるので、比べるときは次年度以降の列を見るほうが実態に近い。マネーフォワードは、12月1日より前に年払いで契約した場合、告知の例に従えば、改定後の料金になるのは1年後の更新からになる。

## 実際に違うところ

:::fact
両社の公式ページで確かめられた違いは次のとおり。

| 項目 | マネーフォワード クラウド確定申告 | やよいの青色申告 オンライン |
| --- | --- | --- |
| 明細の自動取込 | 全プランで銀行・クレジット明細の自動取込。「2,300以上のサービスと連携」（2024年2月自社調べ） | 全プランで金融機関連携。連携できる金融機関は全国1,100件以上、サービスは2,500件以上（2025年8月時点） |
| e-Tax | 全プランで電子申告に対応。アプリからの電子申告には、マイナンバーカードと読み取り対応のスマートフォンが必要 | 全プランでe-Taxに対応。申告データを作成後、e-Tax専用サービスを起動し、スマホアプリで電子署名をして送信する。e-Taxデータの書き出しにも対応 |
| スマホアプリ | 製品トップは「アプリでそのまま電子申告」と案内している | 「弥生 申告」アプリと「弥生 レシート取込アプリ」で取引入力とレシート取込ができる。確定申告書や青色申告決算書の作成はWindowsかMacで行い、アプリでは作成できない |
| 消費税申告・インボイス | 消費税申告書の作成はパーソナル以上。パーソナルミニは利用できない | どのプランでも消費税申告、インボイスの仕訳入力、2割特例に対応 |
| レシート読み取り | 無料枠はミニ月15件、パーソナル月30件、プラス月100件。超過は1件20円（税抜）で、パーソナルとプラスは2026年12月1日から件数制限なし | 料金ページにプラン別の件数制限の記載は見当たらない |
| メール・チャット | 全プランで利用可（操作方法） | ベーシック以上。セルフはWebFAQのみ |
| 電話 | パーソナルプラスのみ。操作方法が対象で、仕訳や税務の相談は受け付けない | ベーシック以上。ベーシックはサポート契約期間中10回まで |
| 仕訳・申告の相談 | 料金ページに該当するプランの記載はない | トータルに仕訳相談・経理業務相談・確定申告相談が付く |
| 併せて使えるサービス | 請求書・経費・給与・契約など12サービスが基本料金に含まれる | クラウド請求書サービスMisocaと連携でき、同時に申し込める。全プランに福利厚生サービスが付く |
:::

両社とも、青色申告をe-Taxで行えば青色申告特別控除が65万円になると案内している。弥生は加えて、2027年（令和9年）分から改正される控除75万円の要件のうち「優良な電子帳簿」に対応していると書いている。マネーフォワードの料金ページには、会計データをAIツールから確認・操作できるMCPサーバー機能に追加料金はかからないというFAQもある。

確かめられなかった点も書いておく。連携できる金融機関の数は、両社で数え方も調査時点も違うので、数字の大小だけでは比べられない。自分が使っている銀行やカードが対象かどうかは、それぞれの公式の一覧で確かめる必要がある。やよいの白色申告 オンラインで消費税申告ができるかどうかは、今回見た料金ページからは確認できなかった。

## どんな人に、どちらが合うか

順位を付ける話ではない。上の事実から、条件ごとに当てはまりやすい側を整理する。

:::guess
- **インボイス登録をしていて、費用を抑えたい人**は、弥生のセルフが条件に合いやすいとみられる。消費税申告まで含めて次年度以降が年額11,800円+税で、初年度は無料だからだ。ただしサポートはWebFAQだけになる。
- **操作に迷ったとき、チャットやメールで聞きたい人**は、見方が分かれる。マネーフォワードは最も安いパーソナルミニでもメール・チャットが使える。弥生はベーシック（次年度以降は年額22,800円+税）からになる。
- **仕訳や申告のやり方そのものを相談したい人**は、弥生のトータルが当てはまるとみられる。マネーフォワードの電話サポートは操作方法が対象で、仕訳や税務の相談は対象外と明記されている。
- **スマートフォンだけで申告まで終えたい人**は、マネーフォワードの案内のほうが条件に近いと読める。弥生は申告書の作成をWindowsかMacで行うと書いている。
- **請求書や経費、給与なども同じ契約でまとめたい人**は、12サービスが基本料金に含まれるマネーフォワードが候補になる。請求書だけでよければ、弥生もMisocaと連携できる。
- **免税事業者で、消費税申告が要らない人**は、マネーフォワードのパーソナルミニ（年払い10,800円、改定後も変更なし）と弥生のセルフ（次年度以降11,800円+税）がほぼ同じ価格帯になる。この場合は、価格より、メール・チャットが要るかどうかや、使っている金融機関が連携の対象かどうかで決めることになりそうだ。
- **白色申告の人**は、やよいの白色申告 オンラインのフリープランが無料で使える。サポートが要るならベーシックからになる。
:::

## 乗り換えを考えるきっかけ

:::fact
弥生の料金ページのFAQによれば、他社の申告ソフトから書き出した仕訳データ（CSV形式）を取り込める。マネーフォワードの告知によれば、料金改定は2026年12月1日以降に更新となる契約から適用され、AI-OCRのオプション料金の廃止は、契約の更新時期にかかわらず同日以降の利用分から適用される。
:::

:::guess
乗り換えのきっかけになりそうなのは、三つとみられる。一つめは、インボイス登録で課税事業者になったとき。マネーフォワードではパーソナルミニからパーソナルへの変更が必要になり、弥生ではプランを変えずに済む。二つめは、マネーフォワードのパーソナルで契約の更新日が2026年12月1日以降に来るとき。年払いは15,360円から22,560円になるので、更新日の前に条件を見直す人が出ると推測される。三つめは、弥生で初年度が終わるとき。更新の案内メールが届いた時点で、通常の年額に見合うかを判断することになる。逆に、レシートを多く読み取る人にとっては、件数制限がなくなるマネーフォワードの改定が、残る理由になる可能性もある。
:::

## なぜ料金表の切り方が違うのか

ここからは当サイトの本題だ。2社は同じ「確定申告ソフト」を売りながら、値段の差を付ける場所が違う。

:::fact
マネーフォワードの料金表は、プランの差を機能で付けている。消費税申告書の作成、口座残高照合、収益・費用レポート、証憑の保存件数（ミニは1,000件まで）、レシート読み取りの無料枠がプランによって変わる。一方、メール・チャットサポートは全プランに付く。弥生の料金表は逆で、機能は全プラン同じとし、WebFAQ、操作質問（電話・メール・チャット）、業務相談の3段でプランを分けている。
:::

:::guess
この違いは、それぞれの会社が何を原価とみているかの表れと推測される。マネーフォワードは、請求書や経費などを含む12サービスを一つの基本料金に入れている。確定申告は入口で、事業が育って消費税申告や他の業務が要るようになるほど、上のプランへ進む作りとみられる。弥生は、ソフトの機能は一律にして、人が答えるサポートにだけ値段を付けている。人件費がかかる部分に価格を寄せ、ソフトそのものの値段は低く保つ設計だと読める。入口の作りも違う。マネーフォワードは1ヶ月の無料トライアルで、自動では課金に進まない。弥生は初年度を無料にする代わりに決済方法の登録を求め、2年目の自動更新につなげている。短い試用で有料に切り替えてもらう形と、1年使ってもらってから通常価格に移ってもらう形の違いとみられる。
:::

それぞれの事業の数字と技術構成は、[マネーフォワード クラウドの解剖記事](/ja/articles/moneyforward-cloud)と[弥生の解剖記事](/ja/articles/yayoi)で詳しく扱っている。

年額の数字だけを並べても、2社の違いは見えにくい。値段を付けている対象が、片方は機能、片方は人のサポートだからだ。自分に要るのが消費税申告なのか、質問できる窓口なのか、スマートフォンで終わる手軽さなのか。それを先に決めると、料金表のどの行を見ればよいかが決まる。
