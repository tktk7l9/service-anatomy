[シン・レンタルサーバー](/ja/articles/shin-rental-server)と[エックスサーバー](/ja/articles/xserver)は、どちらもエックスサーバー株式会社が売る、WordPressのブログや小さな事業のサイト向けの共用レンタルサーバーだ。同じ会社の二つの商品が、同じ比較の棚に並んでいる。2本の解剖記事を重ねると、違いは基盤の性能よりも、同じ段のCPUとメモリをどう約束し、ディスクと値札をどうずらし、誰に紹介してもらうかに出ている。

この記事は、両サービスの公式ページを2026年10月11日に読み直してまとめた。当サイトは両方を同じ条件で契約して表示速度や安定性を測ってはおらず、体感の優劣は扱わない。料金はすべて税込で、契約期間分を前払いしたときの月額換算だ。

## 会社：一つの会社に、二つの看板

:::fact
エックスサーバー株式会社の会社概要と沿革（2026-10-11時点）によれば、同社は2004年1月23日に設立され、本社は大阪市北区のグランフロント大阪、資本金は1億円（資本準備金含む）。共用レンタルサーバーのエックスサーバーは、2003年7月に屋号のエックスサーバーとして提供を始めた。同じ沿革によれば、同社は2021年5月に新世代レンタルサーバーサービス『wpXシン・レンタルサーバー』（現『シン・レンタルサーバー』）を始めた。シン・レンタルサーバーのお知らせ（2025-09-02）によれば、シンアカウントで提供するサービスは、グループ再編にともない2025年10月1日付でグループ会社のエックスサーバー株式会社に移管された。エックスサーバーのトップページは、国内シェアNo.1（注記によれば2026年6月時点のW3Techsの調べ）、導入企業26万社、運用サイト数250万件をうたい、注記は、導入企業数を2026年9月時点の、運用サイト数を2025年9月時点の、エックスサーバーと法人向けのXServerビジネスの合計とする。シン・レンタルサーバーのトップページは「国内最速No.1」をうたい、運用できるコンテンツのジャンルに制約がないと書く。
:::

| 項目 | シン・レンタルサーバー | エックスサーバー |
| --- | --- | --- |
| 始まり | 2021年5月（『wpXシン・レンタルサーバー』として） | 2003年7月 |
| 運営 | エックスサーバー株式会社（2025年10月1日に移管） | エックスサーバー株式会社 |
| 通常プランの名前 | ベーシック・スタンダード・プレミアム | スタンダード・プレミアム・ビジネス |
| トップページの看板 | 「国内最速No.1」、コンテンツのジャンルに制約がない | 国内シェアNo.1、導入企業26万社、運用サイト数250万件 |

:::pull
CPUとメモリの段は同じ数字だ。違うのは、その数字を約束するかどうかと、ディスクと値札のずらし方にある。
:::

## リソースと基盤：同じ段を、保証するか、割り当てるか

:::fact
エックスサーバーのサーバー仕様一覧（2026-10-11確認）は、「リソース保証」の値をサーバーごとに示し、sv13001以降のサーバーではスタンダードが仮想6コア・メモリ8GB、プレミアムが8コア・12GB、ビジネスが10コア・16GBとする（sv10001〜sv13000のサーバーでは、スタンダードが4コア・4GBなど、一段低い値）。シン・レンタルサーバーの機能一覧は、通常プランのvCPUとメモリを「サーバーアカウントごとに割り当てられる」コア数と容量とし、ベーシックが6コア・8GB、スタンダードが8コア・12GB、プレミアムが10コア・16GB。シンのビジネスプランのページは、通常プランと異なり、ビジネスプランはプランごとにリソース値を保証すると書き、ビジネス・ベーシックの保証値を4コア・4GBとする。CPUは、エックスサーバーのトップページが第5世代のAMD EPYCの採用を、シンの特長のページが第4世代のAMD EPYCの採用を書く。シンのトップページは最新技術を積極的に導入すると書き、ページの説明文（og:description）は、エックスサーバーのシステムをベースに、エックスサーバーのシステム強化を先んじて最速適用すると書く。ディスクは、エックスサーバーのスタンダード・プレミアム・ビジネスが500GB・600GB・700GB、シンのベーシック・スタンダード・プレミアムが700GB・1,000GB・1,200GBで、どちらもNVMe。転送量は、エックスサーバーのサーバー仕様一覧が無制限（過大な負荷がかかる場合は制限することがある）とし、シンのサーバー仕様一覧は1日あたりの目安をベーシック900GB、スタンダード1,200GB、プレミアム1,500GBとして、目安を大きく上回る場合は速度制限などをすることがあると書く。自動バックアップは、どちらの機能一覧もWeb・メールのデータとMySQLを過去14日分持つと書く。
:::

| 項目 | シン・レンタルサーバー | エックスサーバー |
| --- | --- | --- |
| 6コア・メモリ8GBの段 | ベーシック（割り当て） | スタンダード（sv13001以降でリソース保証） |
| リソースの保証 | ビジネスプランのみ（ビジネス・ベーシックは4コア・4GB） | 通常プランで保証値を明記（サーバーの番号で値が違う） |
| CPU | 第4世代AMD EPYC | 第5世代AMD EPYC |
| ディスク（下の段から） | 700GB・1,000GB・1,200GB | 500GB・600GB・700GB |
| 転送量 | 1日の目安900GB・1,200GB・1,500GB（大きく超えると制限あり） | 無制限（過大な負荷のときは制限あり） |
| 自動バックアップ | 過去14日分 | 過去14日分 |

:::guess
同じ6コア・8GBという数字でも、エックスサーバーはそれを保証の値として書き、シンは割り当ての値として書き、保証は別料金のビジネスプランに回している。シンが同じ段の値段を少し上げてディスクを大きく足しながら、CPUとメモリの保証は付けないのは、容量を重視する客と、安定性に払う法人を、プランの線で分けているためとみられる。CPUの世代は、看板の言葉とは逆に、本体のエックスサーバーの方が新しく書かれている。シンの説明文が先んじて適用するとしているのはシステムの強化で、機器の世代は別の時期に決まっているとみられるが、どのサーバーにアカウントが収容されるかは公開されておらず、ページの記載だけから実際の新旧は判断できない。
:::

## 値札：通常価格はシンが少し高く、10月11日はエックスサーバーだけが割引中

:::fact
シン・レンタルサーバーの料金のページ（2026-10-11確認）によれば、36か月契約の月額はベーシック1,078円、スタンダード2,002円、プレミアム4,004円で、新規契約の表と契約更新の表には同じ金額が並ぶ。ニュース一覧によれば、2025年12月26日から2026年10月7日まで6本のキャンペーンが並び、2本目以降はいずれも前のキャンペーンが終わる日に告知され、最後の「最大半額キャッシュバック」のページは終了したと表示していた。エックスサーバーの料金のページ（同日確認）によれば、36か月契約の通常の月額はスタンダード990円、プレミアム1,980円、ビジネス3,960円で、2026年10月5日17時から11月4日17時までのキャンペーン価格として、それぞれ693円、1,386円、2,772円が適用されていた。12か月契約では、通常の1,100円・2,200円・4,400円が990円・1,980円・3,960円になる。どちらも支払いは契約期間分の一括前払いで、初期費用は0円。
:::

| 36か月契約（税込・月額換算） | シン・レンタルサーバー | エックスサーバー |
| --- | --- | --- |
| 6コア・メモリ8GBの段 | ベーシック 1,078円 | スタンダード 990円（10月11日はキャンペーンで693円） |
| 8コア・メモリ12GBの段 | スタンダード 2,002円 | プレミアム 1,980円（同1,386円） |
| 10コア・メモリ16GBの段 | プレミアム 4,004円 | ビジネス 3,960円（同2,772円） |
| 通常価格の差 | 22円から88円高い | — |
| 2026年10月11日のキャンペーン | なし（前のキャンペーンは10月7日に終了） | 最大30%オフ（11月4日17時まで） |

:::guess
通常価格だけを並べると、シンは同じ段でディスクを足し、値段を22円から88円上げた商品に見える。ただし、シンはここ9か月あまりキャンペーンをほぼ途切れさせずに回しており、10月11日は、たまたま片方だけが割引中という日だった。キャンペーンの有無と割引の幅で実質の値段の大小は入れ替わるため、比べるなら申し込む日の両方の料金のページを見るのが確かだとみられる。
:::

## 試用と特典：規約は同じ文面、無料の特典は少し違う

:::fact
両サービスの利用規約（2026-10-11確認）は、サービスの開始を連絡してから10日間を試用期間とし、期間中に利用料金の支払いを確認した日に本契約を始めると定め、解約の条文では、すでに支払った料金は返還しないと書く。条文の文面はほぼ同じだ。無料の独自ドメインは、エックスサーバーの料金のページによれば、新規契約の場合、スタンダードは12か月の契約で1つ、24か月以上で2つ、プレミアムとビジネスはすべての契約で2つ。シンのサポートのマニュアルは、通常プランは指定の中から1つ、ビジネスプランは2つを無料で提供するとする（特長のページは「いずれか2つ」と書くなど、ページによって書き方が揃っていない）。有料のWordPressテーマ「Xwrite」（通常年9,900円）は、エックスサーバーの料金のページではプレミアムとビジネスで無料（スタンダードは対象外）、シンではベーシックを除くプランで無料になる。
:::

| 項目 | シン・レンタルサーバー | エックスサーバー |
| --- | --- | --- |
| 無料お試し | 10日間 | 10日間 |
| 支払った料金の返還 | しない（規約） | しない（規約） |
| 無料の独自ドメイン | 通常プランは1つ（ビジネスプランは2つ） | スタンダードは12か月で1つ・24か月以上で2つ、プレミアムとビジネスは2つ |
| Xwrite（通常年9,900円） | ベーシック以外で無料 | プレミアムとビジネスで無料 |

## AIエージェントへの入口：同じ部品、6日の差、リモート版の有無

:::fact
エックスサーバーの公式ニュースによれば、XServer APIは2026年4月16日に、MCPサーバーとCLIは5月12日に提供が始まった。シン・レンタルサーバーのニュースによれば、「シンアカウントAPI」は4月22日に、MCPサーバーとCLIは同じ5月12日に始まった。エックスサーバーには、端末へのMCPサーバーの導入やAPIキーの設定なしに、AIエージェントからXServerアカウントにログインして連携を許可するだけで使えるリモート版のMCPサーバー（接続先 `https://api.xserver.ne.jp/mcp`）があり、マニュアルはClaudeのコネクタとしての追加手順を載せる。シン・レンタルサーバーのMCP Serverのマニュアルは、利用者のPC上で `npx -y shincloud-mcp` として動かし、Node.js 18以上とAPIキーが要る方式を説明する。
:::

:::guess
APIを6日遅れで、MCPとCLIを同じ日に出せたのは、二つのサービスが同じ開発の仕組みを共有しているためとみられる。リモート版のMCPを先に本体に置いたのは、利用者の多いエックスサーバーで、ターミナルを使わない客にもAIからの操作を開く順番を選んだと読める。
:::

## 紹介の仕組み：報酬の高い本体と、自社のアフィリエイトを持つシン

:::fact
エックスサーバーのアフィリエイトのページ（2026-10-11確認）によれば、A8.netでの成果報酬はスタンダード5,000円、プレミアム7,500円、ビジネス10,000円。お友達紹介プログラムのページによれば、紹介した側にはお友達の初回の利用料金の最大20%を、紹介されたお友達には初回の利用料金から最大20%の割引を付け、キャンペーンとも併用できる。シン・レンタルサーバーのアフィリエイトのページによれば、ASPはA8.netともしもアフィリエイトで、成約報酬はベーシックが3,000円、スタンダードが5,000円、プレミアムが8,000円。自社のシンクラウドアフィリエイトは、6か月以上の契約を紹介すると3,500円から9,000円を払い、紹介された側は初回の利用料金が10%割引になり、A8.netやもしもアフィリエイトとは併用できない。
:::

| 項目 | シン・レンタルサーバー | エックスサーバー |
| --- | --- | --- |
| ASPの成果報酬（下の段から） | 3,000円・5,000円・8,000円（A8.net・もしもアフィリエイト） | 5,000円・7,500円・10,000円（A8.net） |
| 自社の紹介制度 | シンクラウドアフィリエイト（3,500円〜9,000円、紹介された側は初回10%割引） | お友達紹介プログラム（双方に初回料金の最大20%） |

:::guess
報酬の額だけを見ると、紹介する書き手にとってはエックスサーバーの方が1件あたりの実入りが大きい。シンが自社のアフィリエイトでASPより高い額を払い、ASPとの併用を禁じているのは、ASPの手数料の分を紹介者に回して、自社の経路に書き手を寄せようとしているためとみられる。どちらの紹介記事を読むときも、書き手に報酬が入る仕組みがあることを前提に、通常価格とキャンペーンの期限まで確かめたい。
:::

## 技術構成の重なりは6件

このページの下に出る技術構成の比較は、2本の記事のtechStackを機械的に突き合わせたものだ。共通と判定されたのは、nginx、Apache 2.4、AMD EPYC、オールNVMeのRAID10、MariaDB 10.11、XPageSpeedの6件。AMD EPYCは名前で突き合わせているため共通になるが、上で見たとおり世代は第4世代と第5世代で違う。APIやMCPサーバーは、シンクラウドとXServerという名前の違いで片方だけの扱いになっているが、公開の日付、キーの形式、使える操作の一覧はほぼ同じだ。

選ぶ側の問いは、何に払いたいかで分けられる。同じ値段の段でディスクが多い方がいい、写真や動画を多く置く、キャンペーンの時期に合わせて申し込めるなら、シン・レンタルサーバーが候補になる。CPUとメモリの値が保証として書かれている方がいい、新しい世代のCPUのサーバーがいい、いまのキャンペーンで安く始めたい、紹介の報酬で選ぶ書き手であるなら、エックスサーバーが候補になる。同じ会社の二つの看板を分けているのは基盤の出来ではなく、どの数字を約束し、どの数字を値札に乗せるかという、売り方の設計だ。
