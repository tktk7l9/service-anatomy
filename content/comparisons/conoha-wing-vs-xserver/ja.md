WordPressでブログや小さな事業のサイトを始めるとき、候補に残りやすいのが[ConoHa WING](/ja/articles/conoha-wing)と[エックスサーバー](/ja/articles/xserver)だ。どちらも1台のサーバーを多数の契約者で分け合う共用レンタルサーバーで、入口のプランの容量もCPUもメモリも、公式の数字はほぼ同じに揃っている。差が出るのは、料金の見せ方と、契約の縛り方である。

この記事は、2026年10月1日に両社の公式ページを取得して確認した内容だけで書いている。当サイトは両サービスを契約して速度や使い勝手を測ったわけではない。料金とキャンペーンは短い周期で変わるので、申し込む前に必ず公式の料金ページで最新の数字を確かめてほしい。

## 料金の比較 — 同じ36か月でも、安くなる仕組みが違う

:::fact
ConoHa WINGの料金ページ（2026年10月1日時点）は、表示価格をすべて税込みとし、初期費用は無料とする。料金タイプは2つある。契約期間分を一括で前払いする「WINGパック」と、時間単位で課金する「通常料金」だ。通常料金はベーシックが1時間2.5円で1か月最大1,452円、スタンダードが4.4円で最大2,640円、プレミアムが8.8円で最大5,280円。WINGパックの月額は下の表のとおりで、ページの注記は「2026年10月7日16:00までに新規お申し込みいただいた場合に適用されるキャンペーン料金」と書く。キャンペーン名は「EarlyAutumnキャンペーン」である。

| ConoHa WING・WINGパック（税込・月額） | ベーシック | スタンダード | プレミアム |
| --- | --- | --- | --- |
| 3か月 | 1,331円 | 2,530円 | 5,060円 |
| 6か月 | 1,210円 | 2,365円 | 4,730円 |
| 12か月 | 991円 | 2,145円 | 4,290円 |
| 24か月 | 844円 | 2,035円 | 4,070円 |
| 36か月 | 649円 | 1,925円 | 3,850円 |
:::

:::fact
エックスサーバーの料金ページ（2026年10月1日時点）も、表示価格をすべて税込みとし、初期費用は0円とする。月額は契約期間分の料金を1か月あたりに換算した金額で、支払いは契約期間分の一括前払いだ。ページには「2026/9/7 17:00 - 2026/10/5 17:00までのキャンペーン価格が適用されています」との注記があり、12か月以上の新規契約では利用料金の半額がキャッシュバックされる。表の括弧内は、公式がキャッシュバック後の「実質」として示す月額である。

| エックスサーバー（税込・月額） | スタンダード | プレミアム | ビジネス |
| --- | --- | --- | --- |
| 3か月 | 1,320円 | 2,640円 | 5,280円 |
| 6か月 | 1,210円 | 2,420円 | 4,840円 |
| 12か月 | 1,100円（実質550円） | 2,200円（実質1,100円） | 4,400円（実質2,200円） |
| 24か月 | 1,045円（実質522円） | 2,090円（実質1,045円） | 4,180円（実質2,090円） |
| 36か月 | 990円（実質495円） | 1,980円（実質990円） | 3,960円（実質1,980円） |
:::

2つの表は似ているが、安くなる仕組みが違う。ConoHa WINGの649円は、申し込みの時点で値引きされた金額だ。エックスサーバーの495円は、まず990円で36か月分を前払いし、あとから半額を受け取った場合の換算である。

:::fact
エックスサーバーのキャンペーンページによれば、キャッシュバックは自動では支払われない。申し込み日から満6か月が経過した日の翌月10日頃に、登録したメールアドレスへ申請方法の案内が届き、それに沿って申請する。受け取りは銀行振込、またはコンビニ（セブン銀行ATM・ローソン）。返金やキャンセルなどで申請の時点でサーバー契約が終わっている場合は対象外になる。対象は、キャンペーン期間中に新規に申し込んだサーバーアカウントである。
:::

当サイトの単純な計算では、36か月契約で最初に支払う総額は、ConoHa WINGのベーシックが649円×36で23,364円、エックスサーバーのスタンダードが990円×36で35,640円になる。エックスサーバーは、そこから17,820円が半年以上あとに戻る。手元から先に出ていく金額と、申請を忘れないことの2点が、見かけの月額には表れない違いだ。

### 更新するときの料金

:::fact
ConoHa WINGのよくある質問は、月額649円について「このキャンペーン価格は初回契約時に適用されるもので、内容・割引率は変動または終了することがあります」と書く。WINGパックの自動更新は初期設定で「ON」になっており、更新の決済は契約満了日の30日前に行われ、それ以降のキャンセルはできない。エックスサーバーは2025年10月31日のお知らせで、自動更新・手動更新・新規契約で異なっていた月額料金を統一すると発表しており、12か月・24か月・36か月契約の月額料金に変更はないとした。半額キャッシュバックの対象は新規の申し込みである。
:::

ConoHa WINGの更新時に適用される具体的な月額は、当サイトが確認した公式ページには数字として書かれていなかった。エックスサーバーは、公式の説明に従えば、更新のときはキャッシュバックのない料金表の月額（スタンダードの36か月なら990円）になる。どちらも、最初の契約期間の安さがそのまま続くとは限らない。長く使うつもりなら、初回の月額ではなく、更新後に払う金額を公式で確かめておきたい。

## 入口プランの中身 — 数字は揃い、言葉が違う

:::fact
ConoHa WINGのベーシックは、SSD 500GB・vCPU 6コア・メモリ8GB。料金ページの注記は「メモリ・vCPUコア数は目安値です。共用サーバーの混雑度が低い場合、最大値までご利用いただけます」と書く。エックスサーバーのスタンダードは、ディスクがNVMeの500GB。仕様一覧の「リソース保証」は、sv13001.xserver.jp 以降のサーバーでスタンダードに仮想6コア・メモリ8GBを挙げ、転送量は無制限（過大な負荷が掛かる場合は制限を行う場合がある）とする。
:::

:::guess
コア数とメモリの数字は同じだが、ConoHa WINGは「目安値」、エックスサーバーは「保証」という言葉で示している。同じ6コア・8GBでも、混雑していないときに届く上限なのか、確保される取り分なのかで意味は変わりうる。ただし、どちらも1台を多数の契約者で分け合う共用サーバーであり、この言葉の違いが実際の表示速度にどう表れるかは、公式ページからは判断できない。ConoHa WINGにも、メモリとvCPUを保証する別建ての「ビジネスプラン」があることから、同社はリソースの保証を上位の商品として切り分けているとみられる。
:::

### 速さと稼働率は「各社がそう述べている」数字

:::fact
ConoHa WINGのトップページは「サーバー処理速度No.1」と「稼働率99.99%以上」を掲げる。注記によれば、処理速度は2026年7月の自社調べで、国内シェア90%以上を占める上位10サービスの最下位プランを、h2loadとApache Benchで5回計測した平均値の比較である。稼働率は「サーバーへのアクセスが完全に不能となった状態を障害と定義した場合」の、2025年7月1日から2026年7月31日までの実績値だ。エックスサーバーのトップページも「サーバー速度No.1」と「稼働率99.99%以上の実績」を掲げ、サーバー稼働率は創業以来99.99%以上と書く。
:::

2社がそれぞれ自社の速度を1位と述べている以上、この表示だけで速さの優劣は決められない。どちらも各社の主張であり、当サイトの計測結果ではない。エックスサーバーの速度表示の根拠となる注記の本文は、当サイトが取得したトップページの中では確認できなかった。

## 無料ドメイン・バックアップ・WordPressの道具

:::fact
無料の独自ドメインは、両社とも最大2つで、契約中は更新料がかからない。条件が違う。ConoHa WINGはWINGパックの契約者だけが対象で、通常料金には付かない。1つ目は「.com」「.net」など20種類から、2つ目は .online / .space / .website / .tech / .site / .fun / .tokyo / .shop の8種類から選ぶ。よくある質問によれば、設定後に別のドメインへは変更できず、WINGパックを解約するか通常料金へ変えると、翌年以降の更新費用は有料になる。エックスサーバーは、新規契約の場合、スタンダードは12か月契約で1つ、24か月以上で2つ、プレミアムとビジネスはすべての契約で2つ。スタンダードの12か月未満は対象外だ。スタンダードで選べるのは .com / .net / .org / .info / .biz / .xyz / .link / .click / .blog / .online / .site の11種類で、2つ目は .blog / .site / .online から選ぶ。キャンペーンページは、スタンダードでこの特典を使うには「自動更新設定」を有効にする必要があるとも書く。
:::

:::fact
バックアップは、両社とも全プランで自動かつ無料とし、保持期間も同じ過去14日分である。ConoHa WINGは、Webサイト・メール・データベースを1日1回バックアップし、コントロールパネルから復元できる。エックスサーバーも、Web・メールデータとMySQLデータベースを1日1回バックアップ専用サーバーへコピーし、サーバーパネルから復元できる。エックスサーバーは「データの確実な保全を保証するものではありません」として、利用者自身でもバックアップを取ることを強く勧めている。sv12301.xserver.jp 以前のサーバーでは、Web・メールデータの保持は過去7日間になる。
:::

:::fact
WordPressを始める道具も揃っている。ConoHa WINGの「WordPressかんたんセットアップ」は、サーバー・独自ドメイン・WordPress・WordPressテーマ・SSLをまとめて申し込み、自動で設定する機能で、初めてWINGパックを申し込むときに使える。他社からの引っ越しには「WordPressかんたん移行」があり、公式は移行データサイズが無制限で無料、本番の前にテストサイトで動作を確認できると書く。エックスサーバーには、申し込みと同時にWordPressを設置する「WordPressクイックスタート」と、サーバーパネルから使う「WordPress簡単移行」がある。
:::

## お試し・解約・サポート — いちばん差が出るところ

:::fact
試し方が違う。エックスサーバーは全プランに10日間の無料お試しがあり、期間中に料金を支払うと本契約へ移る。お試し中は、メールアカウントの作成、プログラムによるメール送受信、追加FTPアカウントの作成などが制限される。ただし、WordPressクイックスタートを使って申し込むと無料お試し期間はなく、申し込みと同時に支払いが発生する。よくある質問によれば、解約に料金はかからないが、支払い済みの利用料金は返金されない。
:::

:::fact
ConoHa WINGの公式ページに、無料お試しという制度は見当たらない。代わりに2つの仕組みがある。通常料金は初期費用も最低利用期間もなく、いつでもサーバーを削除すれば解約になり、追加費用はかからない。WINGパックは、契約期間中の途中解約も返金もできない。終了したいときは、契約満了日の30日前までに自動更新を「OFF」にする。WINGパックの契約期間は申し込み月の翌月から始まり、それまでの利用料金は無料で、月初に申し込めば最大31日間は無料で使える。通常料金からWINGパックへは、コントロールパネルから好きなタイミングで変更できる。
:::

:::fact
サポートの窓口は、エックスサーバーが電話（平日10:00〜18:00）、メール（24時間365日受付）、チャット（平日10:00〜18:00）を示し、電話とチャットは内容によりメールでの問い合わせを求める場合があるとする。ConoHa WINGの料金ページは全プランに「電話・メールサポート あり」と書く。ConoHa WINGの電話の受付時間は、当サイトが取得したページの中では確認できなかった。支払いは、ConoHa WINGがクレジットカードと、事前入金型の「ConoHaチャージ」（銀行振込・コンビニ・ペイジー・Amazon Pay・PayPalなどで入金）。エックスサーバーはクレジットカード・銀行振込・ペイジー・あと払い（ペイディ）・コンビニ払い・プリペイド決済である。
:::

:::pull
エックスサーバーは「払う前に10日間さわれる」。ConoHa WINGは「時間単位で払って、いつでもやめられる」。どちらも、長期の前払いに入ったあとは途中で戻れない。
:::

## どんな人にどちらが合うか

順位をつける話ではない。状況ごとに、公式の条件から読み取れる向き不向きを整理する。

- 最初に払う金額を小さくしたい人には、ConoHa WINGのWINGパックが合いやすい。値引きが申し込みの時点で効いており、後日の申請が要らない。
- 半年後の申請を忘れない自信があり、返金後の金額で考えられる人には、エックスサーバーのキャッシュバックが合いやすい。36か月契約なら、公式が示す実質の月額はスタンダードで495円になる。
- 契約する前に管理画面や動作を確かめたい人には、エックスサーバーの10日間の無料お試しがある。ただし、WordPressクイックスタートを使うとお試しは付かない。
- 数日から数週間だけ使うかもしれない人、続けるか決めていない人には、ConoHa WINGの通常料金がある。時間単位の課金で、最低利用期間がない。無料ドメインは付かない。
- 12か月だけ契約して様子を見たい人は、無料ドメインの数に注意したい。エックスサーバーのスタンダードは12か月契約で1つ、ConoHa WINGのWINGパックは契約期間を問わず最大2つである。
- 2つ目のドメインにこだわりがある人は、選べる種類が違う。ConoHa WINGは8種類、エックスサーバーは3種類で、重なるのは .online と .site だ。
- チャットで問い合わせたい人には、公式に窓口を明記しているのがエックスサーバーである。

どちらを選んでも、36か月の前払いは途中でやめても戻らない。初めてで続くかわからないなら、長い契約ほど月額が下がるという誘導と、自分が実際に続ける見込みを分けて考えるのが安全だ。

### 乗り換えを考えるきっかけ

:::guess
両社とも他社からのWordPress移行ツールを用意しているので、乗り換えそのものの手間は以前より小さいとみられる。乗り換えを考えるきっかけになりやすいのは、更新時の料金が初回より上がったとき、無料ドメインの条件が契約の種類と結びついていることに気づいたとき、そして障害やサポート対応に不満が出たときだろう。注意したいのは無料ドメインで、ConoHa WINGはWINGパックをやめると翌年以降の更新費用が有料になると明記している。サーバーを移してもドメインの費用は残るので、乗り換えの損得はサーバー代だけでは決まらないと考えられる。
:::

## 違いの根にあるもの — VPS育ちの値付けと、前払いを続けてきた専業

:::fact
ConoHa WINGは、GMOインターネットグループのプレスリリースによれば2018年9月26日に提供を開始した。運営するGMOインターネット株式会社は東証プライムに上場している（証券コード4784）。エックスサーバーは、コーポレートサイトの沿革によれば2003年7月に共用レンタルサーバーの提供を始めた。
:::

:::guess
料金表の形は、この出自から説明できるとみられる。[ConoHa WINGの解剖記事](/ja/articles/conoha-wing)が書くとおり、「ConoHa」は元々VPSのブランドで、時間単位の課金はそこから持ち込まれた設計だ。通常料金という時間課金の上限額を基準に置き、そこからの割引率としてWINGパックを見せる。だから同じ料金表に「いつでもやめられる」と「途中解約できない」が並ぶ。上場企業のグループの中で、ドメインやAIライティングツールと組み合わせて売る商品でもあり、期限つきのキャンペーンを重ねて新規の申し込みを集める運び方になっていると推測される。
:::

:::guess
エックスサーバーは、[解剖記事](/ja/articles/xserver)が書くとおり、共用サーバーを長く売り続けてきた会社だ。料金表は契約期間ごとの定価が先にあり、割引は定価を書き換えずにキャッシュバックとして外に出している。2025年に自動更新・手動更新・新規契約の月額を統一したことも合わせると、定価の表は動かさず、新規の獲得はキャンペーンで、継続は長期契約への誘導で行う、という分け方とみられる。10日間の無料お試しを残しているのも、時間課金を持たない会社が「試してから払う」を用意する方法だと考えられる。
:::

:::guess
つまり2社の違いは、どちらが安いかより、解約の自由をどこに置いたかにあると当サイトはみる。ConoHa WINGは、自由を通常料金という別の料金タイプに置き、割引と引き換えにそれを手放させる。エックスサーバーは、自由を最初の10日間に置き、その後は前払いの期間で固める。共用サーバーは長く留まる契約者が増えるほど1契約あたりの原価が下がる事業なので、どちらの設計も、入口を広くして長期契約へ導く点では同じ方向を向いていると推測される。
:::

ConoHa WINGとエックスサーバーは、入口のプランの数字がほぼ同じに揃っている。違うのは、値引きを先に受けるか後から受け取るか、試す自由が時間課金にあるか無料の10日間にあるか、という契約の形だ。月額の数字は来週には変わっているかもしれない。変わりにくいのは、VPSから育った会社と、共用サーバーを売り続けてきた会社という、料金表の裏にある設計のほうである。
