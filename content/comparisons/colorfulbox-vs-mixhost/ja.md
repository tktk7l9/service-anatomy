[カラフルボックス](/ja/articles/colorfulbox)と[mixhost](/ja/articles/mixhost)は、WordPressのブログや小さな事業のサイトを置く国内の共用レンタルサーバーとして、並べて比べられることが多い。どちらも大阪の小さな会社が、海外のホスティング会社で広く使われる市販の部品を組み合わせて動かし、アダルトサイトの運営を認め、紹介をA8.netのアフィリエイトに任せる。2本の解剖記事を重ねると、2社の違いは部品の性能よりも、同じ部品の上で何を標準にし、何を有料や上位のプランに回したかに出ている。

この記事は、両社の公式の料金・仕様・特徴のページ、ヘルプ、お知らせ、会社概要を2026年10月11日に読み直してまとめた。当サイトは両方のサーバーを同じ条件で契約して表示速度や安定性を測ってはおらず、体感の優劣は扱わない。料金はすべて税込で、契約期間分を前払いしたときの月額換算だ。

## 会社と規模：大阪の小さな会社が2つ

:::fact
アズポケット株式会社の会社概要（2026-10-11時点）によれば、mixhostを運営する同社は2016年4月11日に設立され、本社は大阪市中央区南船場、資本金は200万円、届出電気通信事業者（E-28-03926）で、公認パートナーとしてcPanel, L.L.C.、LiteSpeed Technologies Inc.、Softaculous Ltd.を挙げる。mixhostのトップページは、個人から大企業まで100万サイト以上に導入されていると書く。カラフルボックスの会社情報のページ（同日時点）によれば、運営する株式会社カラフルラボは2018年1月23日に設立され、本社は大阪市西区阿波座、資本金は300万円、届出電気通信事業者（E-30-04229）で、2018年7月にレンタルサーバー「ColorfulBox」の提供を始めた。累計ユーザーは24,000超（2026年9月時点）とする。
:::

| 項目 | カラフルボックス | mixhost |
| --- | --- | --- |
| 運営会社 | 株式会社カラフルラボ（大阪市西区） | アズポケット株式会社（大阪市中央区） |
| 設立 | 2018年1月（サービス開始は同年7月） | 2016年4月 |
| 資本金 | 300万円 | 200万円 |

公表している規模は、片方が利用者の数、もう片方がサイトの数で、数え方が違うため大小は比べられない。

:::pull
部品表はほとんど同じだ。違いは、同じ部品の上で、何を全員に配り、何を上のプランに回したかにある。
:::

## 部品表：同じ市販の部品で組む

:::fact
カラフルボックスの仕様のページ（2026-10-11確認）によれば、WebサーバーはLiteSpeed 6.x.x、OSはCloudLinux、データベースはMariaDB 10.6.x、PHPは5.3系から8.3系まで、サーバーはIntel Xeon / AMD EPYCの最大64コアと最大512GBのメモリで、ストレージは高速ピュアSSDのRAID構成。特徴のページは、管理画面にcPanelを、セキュリティにImunify360を使い、WAF / IPS / IDSを全プランで標準にすると書く。mixhostの料金・機能の比較表（同日確認）は、全プランでLiteSpeed Webサーバー、HTTP/3、CloudLinux、cPanel、MariaDB、PHP 5.6〜8.5に〇を付ける。同じページは、複数のサーバーで多重化したクラウドサーバーを使い、NVMe SSDのストレージを複数のストレージサーバーにリアルタイムで複製すると説明する。mixhostのお知らせ（2026-09-07）は、ライトプランにもImunify360を導入したと告知した。当サイトの実観測（2026-10-11）では、mixhost.jp と www.colorfulbox.jp はどちらも server: cloudflare を返し、契約者のログインの入口である accounts.mixhost.jp と secure.colorfulbox.jp は、どちらも clientarea.php へ転送してWHMCSで始まる名前のクッキーを返した。
:::

2社とも、管理画面、Webサーバー、セキュリティ、課金の仕組みを自社で作らず、既製品のライセンスで組み立てているとみられる。少人数の会社でも大手に近い機能の幅を出せる反面、部品の性能では差が付きにくい。そのぶん、2社が自分で決められるのは、サーバーをどこに置き、バックアップをどこまで配り、どの保証を誰に付けるか、という設計の部分になる。カラフルボックスは2つの地域にサーバーを持つことに、mixhostは1つの地域の中でクラウドとして多重化することに、それぞれ投資したと読める。
:::

## 値段の付け方：初回を半額にするか、更新との差を小さくするか

:::fact
カラフルボックスの料金のページ（2026-10-11確認）によれば、36か月契約の月額は、BOX1が528円（更新も528円）、BOX2が初回484円・更新968円、BOX3が814円・1,628円、BOX4が1,089円・2,178円で、BOX2以上は「初回限定割引」として初回50%割引の価格と更新価格の二段になる。初回の割引が付くのは12・24・36か月の契約で、6・3・1か月の契約は1つの価格だけだ。契約期間は1・3・6・12・24・36か月、3か月以上なら初期費用は無料で、1か月契約だけ2,200円かかる。mixhostの料金表（同日確認）によれば、36か月契約の月額は、ライトが初回495円・更新748円、スタンダードが858円・1,298円、プレミアムが968円・1,518円、ビジネスが1,408円・2,178円で、36か月の初回の割引率は33%から36%。契約期間は3・6・12・24・36か月で、割引は初回の支払い期間だけに付く。2025年4月1日のお知らせによれば、mixhostは同年4月22日から更新価格を下げ、36か月契約ではスタンダードを2,178円から1,298円、プレミアムを3,278円から1,518円、ビジネスを5,478円から2,178円にした。
:::

| 36か月契約（税込・月額換算） | カラフルボックス | mixhost |
| --- | --- | --- |
| 最も安いプラン | BOX1：初回528円・更新528円 | ライト：初回495円・更新748円 |
| 2番目 | BOX2：初回484円・更新968円 | スタンダード：初回858円・更新1,298円 |
| 3番目 | BOX3：初回814円・更新1,628円 | プレミアム：初回968円・更新1,518円 |
| 4番目 | BOX4：初回1,089円・更新2,178円 | ビジネス：初回1,408円・更新2,178円 |
| 更新で何倍になるか | BOX1は据え置き、BOX2以上は2倍 | 約1.5〜1.6倍 |
| 契約期間 | 1・3・6・12・24・36か月 | 3・6・12・24・36か月 |

プランの中身は、2社で書き方が違う。カラフルボックスはSSDの容量とvCPU、メモリで示し、BOX1は200GB・1vCPU・2GB、BOX2は700GB・6vCPU・8GBだ。mixhostはディスク容量、推奨の月間PV数、ファイル数（inode）で示し、ライトは100GB・10万PV・10万ファイル、スタンダードは容量無制限・20万PV・20万ファイルとする。同じ「2番目のプラン」でも中身が揃っているわけではないため、上の表は、それぞれの料金表の並びをそのまま並べたものとして読みたい。

:::guess
カラフルボックスは、最も安いBOX1だけを最初から更新と同じ値段にし、BOX2以上は初回を半額にして更新で2倍に戻す。入口の安さで選ばれ、2年目以降で回収する、国内の共用サーバーで一般的な型を、倍率を揃えて分かりやすくしたものとみられる。mixhostは初回の割引を3割台に留め、2025年に更新価格を下げて、初回と更新の差を約1.5〜1.6倍まで縮めた。長く使う客と、その客に勧めるアフィリエイトの書き手に「更新しても大きくは上がらない」と言える形を選んだと読める。3年で乗り換えるつもりなら初回の安さが、5年以上使うつもりなら更新価格が効くため、どちらが安いかは使う年数で変わる。
:::

## バックアップ：最も安いプランにも別の地域か、ライト以外に別のデータセンターか

:::fact
カラフルボックスの特徴のページ（2026-10-11確認）によれば、「地域別自動バックアップ」は過去14日分の自動バックアップを、契約時に選んだ地域とは別の地域に置く仕組みで、全プランで標準・無料。トップページは、バックアップ先を同じサーバー内ではなく物理的に離れた別の地域に設定していると書く。料金のページは、サーバーを置く地域を東日本と西日本から選べるとする（既定は東日本）。mixhostの料金・機能の比較表（同日確認）によれば、自動バックアップは1日1度、外部のバックアップサーバーにファイルとデータベースを取り、スタンダード以上で14日分を持ち、ライトにはない。バックアップは別のデータセンター内の複数のストレージサーバーに重複して置かれ、ストレージはイレブンナイン（99.999999999%）の耐久性を持つと説明する。サーバーのリージョンは東京だ。
:::

| 項目 | カラフルボックス | mixhost |
| --- | --- | --- |
| 自動バックアップの対象 | 全プラン（最も安いBOX1を含む） | スタンダード以上（ライトはなし） |
| 保存する期間 | 14日分 | 14日分 |
| 置き場所 | 契約時に選んだ地域とは別の地域 | 別のデータセンター内の複数のストレージサーバー |
| 追加の料金 | なし | なし（スタンダード以上の料金に含む） |

:::guess
どちらも「サーバーが壊れても別の場所に控えがある」という同じ守りを持つが、配る範囲が違う。カラフルボックスは、地域を分けたバックアップを看板にしているため、いちばん安いプランから外さないとみられる。mixhostはライトを「費用を抑えてWebサイトを運営したい方向けのエコプラン」と位置づけ、バックアップを外すことで初回495円という入口の値段を作ったと読める。ライトを選ぶなら、バックアップを自分で取る手間まで含めて値段を見積もる必要がある。
:::

## 試し方と返金：払う前に試すか、払ってから返してもらうか

:::fact
カラフルボックスの料金のページ（2026-10-11確認）によれば、全プランに申し込み日から30日間の無料お試し期間があり、クレジットカードなしで試せる。お試し期間中に本契約しても、契約はお試しの30日が終わってから始まる。特定商取引法に基づく表記によれば、申し込みの解約はクレジットカード決済でも銀行振込でも申し込み後8日以内に限って受け付け、取得済みのドメインの料金は解約・返金できず、返金に応じるかどうかは同社の判断で決まる。mixhostの返金保証のヘルプ（同日確認）によれば、レンタルサーバー、アダルトレンタルサーバー、海外レンタルサーバーには30日間の返金保証があり、初回の申し込みから30日以内が対象で、30日以降や更新時には使えない。解約の手続きで「直ちに解約する」を選び、そのうえでサポートに連絡しないと返金は自動では行われない。ドメインや専用クラウドレンタルサーバーなどは対象外で、銀行振込の場合は2,200円の返金手数料がかかり、クレジットカードとPayPalは手数料がかからない。
:::

| 項目 | カラフルボックス | mixhost |
| --- | --- | --- |
| 払う前に試す | 30日間の無料お試し（カード不要） | なし |
| 払ったあとに戻す | 申し込み後8日以内の解約（返金は同社の判断） | 30日間の返金保証（解約後にサポートへ連絡） |
| 対象外 | 取得済みのドメインの料金 | ドメイン、専用クラウドなど |

:::guess
2社とも「30日」を入口の安心に使うが、向きが逆だ。カラフルボックスは払う前に30日を渡し、払ったあとの逃げ道は8日と短い。mixhostは先に払ってもらい、合わなければ30日以内に返す。前者は試してから決めたい人に、後者は申し込んですぐ本番の移行を始めたい人に合う作りとみられる。どちらも、返金や解約の手続きは自分から動かないと始まらない点は同じだ。
:::

## 稼働の保証：全プランのSLAか、法人向けだけのSLAか

:::fact
mixhostの料金・機能の比較表（2026-10-11確認）は、全プランに「稼働率99.99%保証」の〇を付ける。品質保証制度（SLA）のヘルプによれば、対象はレンタルサーバーとクラウドレンタルサーバーで、wwwとメールのサービスが完全に使えない時間を障害として数え、月間稼働率が99.99%を下回り99.50%以上なら月額費用の10%、99.50%を下回ると30%を返す。申請の期限は障害が起きた月の翌月末日までで、返金は預り金かポイントとして次の更新などに充てる。カラフルボックスのトップページのよくある質問（同日確認）は、稼働率99.99%以上を保証するSLAを、カラフルボックスと共通の基盤に加えて法人向けの「カラフルビジネス」が全プランで備える機能の1つとして挙げる。法人向けのページによれば、カラフルビジネスは基準を下回った月に、申請なしで利用残高を自動で付与し、料金はスターターの月2,280円から始まる。
:::

| 項目 | カラフルボックス | mixhost |
| --- | --- | --- |
| 稼働率99.99%のSLA | 法人向けのカラフルビジネス（月2,280円から） | 全プラン（ライトを含む） |
| 下回ったとき | 利用残高を自動で付与（申請不要） | 月額の10%か30%を預り金・ポイントで返す（翌月末までに申請） |

:::guess
SLAの置き場所の違いは、2社が誰に何を売りたいかを映しているとみられる。mixhostは安いライトにまで稼働の保証を付け、個人でも「止まったら返す」と約束する。カラフルボックスは稼働の保証を、専用IPやSPF・DKIM・DMARC、.co.jpのドメインと束ねて法人向けの商品にし、個人向けのBOXプランでは地域別のバックアップを守りの看板にしている。止まらないことに払うか、壊れても戻せることに払うか、という選び方の違いと読める。
:::

## アダルトサイトの受け方：同じ料金表で認めるか、別のサーバーと別のIPに分けるか

:::fact
mixhostの料金・機能の比較表（2026-10-11確認）は、通常のレンタルサーバーの全プランで「アダルトサイト」に〇を付ける。アダルトレンタルサーバーのページは、通常のレンタルサーバーと同じ料金表を載せ、裁判所による命令でない限り、捜査機関からの照会や第三者からの請求であっても、客の同意なく個人情報を開示することはないと書く。カラフルボックスの特徴のページ（同日確認）によれば、アダルトサイトは通常のサーバーとは別のサーバーで受け、一般のホームページがアダルトサイトと同じIPになることはない。料金のページによれば、アダルト対応のサーバーはBOX2からBOX8までで、36か月契約のBOX2は初回528円・更新1,320円（初回60%割引）、通常のサーバーとの間でプランを変えることはできない。アダルト対応サーバーのページは、BOX2以上にプレミアムのCDNを載せると書く。
:::

:::guess
mixhostはアダルトサイトを通常のプランの延長として扱い、プライバシーの保護を前面に出して受ける。カラフルボックスは、同じサーバーに一般のサイトとアダルトサイトが同居すると、IPアドレスの評判やメールの到達に影響しうることを避けるため、サーバーとIPを分け、そのぶんの原価をCDNを含めた高めの更新価格に乗せているとみられる。アダルトサイトを運営する側から見れば、同じ値段で手軽に始められるのがmixhost、一般のサイトと住み分けた環境に払うのがカラフルボックス、という違いになる。
:::

## 紹介の仕組み：報酬の表を見せるか、2つのASPと友達招待か

:::fact
カラフルボックスのアフィリエイトのページ（2026-10-11確認）によれば、アフィリエイトはA8.netで提供され、参加費は無料でノルマもなく、報酬の表を公開する。報酬（税別）は、30日間の無料お試しの申し込みが1円、BOX1の36か月契約が7,000円、BOX2の36か月契約が8,000円などだ。mixhostのアフィリエイトのページ（同日確認）によれば、広告はA8.netとafbの2つのASPで配信し、報酬の額は公式ページに書かれていない。お友達招待のページによれば、契約者が専用の招待リンクとクーポンコードを知らせ、相手はそれで申し込むと1,000円の割引を受け、30日間の利用が確認されると紹介した側に1,000円がクレジットとして入る。招待の回数に制限はない。
:::

| 項目 | カラフルボックス | mixhost |
| --- | --- | --- |
| アフィリエイト | A8.net（報酬の表を公式に公開） | A8.netとafb（報酬の額は公式ページに記載なし） |
| 例 | BOX2の36か月契約で8,000円（税別）、無料お試しで1円 | — |
| 契約者による紹介 | — | 紹介した側に1,000円のクレジット、紹介された側に1,000円の割引 |

:::guess
2社とも、広告費を先に払うより、成約したときだけ払うアフィリエイトに集客を寄せているとみられる。カラフルボックスが無料お試しの申し込みにまで1円を付けるのは、カード不要のお試しを入口にした設計と噛み合っている。mixhostは報酬をASPの中に置いたまま、契約者どうしの紹介にも1,000円ずつを配り、使っている人の口コミも集客の道にしていると読める。どちらの紹介記事を読むときも、書き手に報酬が入る仕組みがあることを前提に、初回の価格だけでなく更新価格まで確かめたい。
:::

## 技術構成の重なりは8件

このページの下に出る技術構成の比較は、2本の記事のtechStackを機械的に突き合わせたものだ。共通と判定されたのは、Cloudflare、CloudLinux、cPanel、Imunify360、LiteSpeed Web Server、MariaDB、PHP、WHMCSの8件で、当サイトの比較のなかで最も多い（これまでの最多は4件）。片方だけに出る技術には、記事で取り上げたかどうかの差も含まれる。たとえばSitejetはカラフルボックスの側だけに出るが、mixhostの料金・機能の比較表も全プランでSitejetに〇を付けている。LiteSpeed Cacheはmixhostの側だけに出るが、カラフルボックスの特徴のページもLiteSpeed Cacheを標準で載せると書く。片方だけに出る技術のうち、各社が自社の特徴として打ち出しているのは、カラフルボックスのColorfulBox CDNと、mixhostが独自に開発したと書くWordPressの高速化技術RocketBoosterだ。

選ぶ側の問いは、何に払いたいかで分けられる。いちばん安いプランでもバックアップを持ちたい、カードを登録せずに30日試してから決めたい、サーバーを置く地域を東日本と西日本から選びたい、法人として専用IPや.co.jpのドメインまで束ねたいなら、カラフルボックスが向く。安いプランでも稼働の保証が欲しい、更新で値段が大きく上がるのを避けたい、新しいPHPをすぐ使いたい、払ってから30日以内なら返金を受けたいなら、mixhostが向く。同じ部品で組んだ2つのサーバーを分けているのは、速さよりも、壊れたとき、止まったとき、合わなかったときに、誰が何を負うかの決め方だ。
