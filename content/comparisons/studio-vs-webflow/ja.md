[Studio](/ja/articles/studio)と[Webflow](/ja/articles/webflow)は、どちらも「コードを書かずにデザインからホスティングまで終わらせる」道具として並べられる。ただ、料金表と公式の説明を横に置くと、想定している使い手も、預かり方も違う。この記事は両社の公式ページを2026年11月2日に読み、書かれている数字と条件を並べたものだ。当サイトは両サービスで実際にサイトを運用した体験を書いているのではなく、公開情報を突き合わせている。料金や上限は変わるので、契約の前に必ず公式ページを確認してほしい。なおWebflowのヘルプセンターは当サイトの取得を拒否したため、Webflow側の記述は料金ページと製品ページの範囲にとどめた。

## 料金を並べる

:::fact
以下は、Studioの料金ページ・ヘルプと、Webflowの料金ページ（いずれも2026-11-02閲覧）の内容を当サイトが並べ直したものだ。Studioの利用規約は表示価格を税込としている。Webflowの料金ページには「All prices in USD, per site, plus applicable taxes added at checkout」とあり、米ドル建て・サイト単位で、税は決済時に加算される。Webflowの月額は年払いの場合の表示で、ページには年払いで最大40%安くなるとある。

| 項目 | Studio | Webflow |
| --- | --- | --- |
| 無料プラン | Free（50ページ、CMSモデル3、公開アイテム100、ストレージ5GB、フォーム回答の閲覧100件） | Starter（webflow.ioドメイン、静的2ページ、帯域1GB、フォーム送信50件、CMSアイテム50） |
| 最安の有料 | Mini 年払い月590円・月払い1,290円（2ページ+404ページ、独自ドメイン可） | Basic 年払いで月15ドル（静的300ページ、帯域10GB、独自ドメイン可、CMSなし） |
| 個人向けのCMS | Personal 年払い月1,190円・月払い1,720円（150ページ、CMSモデル5、公開アイテム1,000） | 該当するプランはなく、次のPremiumから |
| 事業向けのCMS | Business 年払い月3,980円・月払い5,460円（300ページ、モデル10、公開アイテム5,000） | Premium 年払いで月25ドルから（CMSアイテム20,000、コレクション40、帯域50GB〜2.5TBから選択） |
| 上位 | Business Plus 年払い月9,980円・月払い12,900円（モデル30、公開アイテム15,000、同時接続1,000件保証） | Team 月2,500ドル（年契約が必須。LocalizeやAEOエージェントなどを含む） |

:::fact
Studioは適格請求書発行事業者として登録しており、有料プランの支払いには請求書が発行されるとヘルプで案内している。Webflowの料金ページの範囲では、日本の適格請求書についての記載は確認できなかった。
:::

:::guess
為替で換算して優劣をつけるより、課金の単位の違いを見るほうが役に立つとみられる。Studioの上限はページ数とCMSの数で、Miniのような極端に小さなプランもある。Webflowの上限は静的ページ数に加えて帯域で、トラフィックが増えると上位のPremiumの選択肢へ移っていく。Studioは2026年にアクセス数の上限を外したので、急なアクセスの増加で料金が変わる心配は小さくなった。一方でStudioのBusinessとBusiness Plusは、ページ数の上限が同じ300ページだ。CMSの動的ページは1ページと数えるので、数千件の記事を持つサイトでは問題にならないが、固定ページが300を超えるサイトはEnterpriseの相談になると考えられる。
:::

## 作り方の違い

:::fact
Studioの公式ページは操作を積み木に例え、レイアウトは箱の組み合わせで作り、レスポンシブは自動で対応すると説明する。Figmaのデザインを貼り付けて変換するプラグインもある。エディタのページは9,200種類以上のフォントが無料で使えると書き、モリサワのTypeSquareを挙げている。Webflowのデザイン機能のページは、flexboxとCSS gridからインラインブロックや絶対配置まで、レイアウトを直接制御できると説明している。料金ページによれば、Premiumにはコードコンポーネントが含まれ、開発者が書いた、またはAIが生成したコンポーネントをキャンバスに置ける。
:::

:::guess
学ぶ順番が違うと考えられる。Studioは箱とレスポンシブの設定を覚えれば形になり、CSSの知識がなくても進めやすいとみられる。Webflowは最初の山が高いが、覚えたことがCSSそのものなので、そのまま標準の知識として残る。社内のマーケターや非エンジニアのデザイナーが自分で更新するならStudioの入口の低さが効き、フロントエンドの知識を持つ人が細かく制御したいならWebflowの語彙が効く。日本語の本文の見え方を重視するなら、モリサワ書体を無料で使えると公式に書かれている点はStudioの強みだ。Webflowで同じことをしようとする場合のライセンスの扱いは、今回の確認範囲に含めていない。
:::

## 書き出しと拡張の出口

この項目が、2つのサービスの最も大きな違いだ。

:::fact
Studioのヘルプによれば、デザインデータ、ページ情報、公開サイトのHTML・CSS・JavaScript、CMSのデータはいずれも書き出せず、公開できるのはStudioのサーバーだけだ。書き出せるのはフォーム回答のCSVに限られる。Webflowの料金ページのFAQは、有料のWorkspaceプランならサイトを書き出してどこにでもホストでき、表記の義務もないと書く。ただし注記があり、動的コンテンツはコレクションごとに書き出す必要があり、フォームは動かなくなる。また、書き出したコードをWebflowに取り込み直すことはできず、Webflowのサイトは Webflowの中でしか開発できないとも書いている。
:::

:::fact
外部とのつなぎ方も異なる。StudioはBusiness以上でData Connect APIを使え、Notion、microCMSなどの外部データを動的なリストやページに表示できる。Businessは一覧エンドポイント1つまで、Business Plus以上は制限がない。カートと決済は提供しておらず、外部サービスの埋め込みやリンクで実現する。Webflowは、料金ページにリクエスト数やCPU時間の単位で超過分を課金するWebflow Cloudを載せ、製品ページはCloudflare Workersの上でNext.jsとAstroのアプリを動かせると説明している。Ecommerce用のサイトプランも別に用意している。
:::

:::pull
Studioは出口を作らず、Webflowは細い出口を残している。その差は、サイトが10年続くと考えたときに効いてくる。
:::

:::guess
Webflowの書き出しも、完全な引っ越しの道具ではないとみられる。公式の注記どおりフォームは動かなくなり、CMSはコレクション単位の持ち出しになる。それでも「HTMLとCSSが手元に残る」ことと「最初から作り直す」ことの差は大きい。発注者の社内規程で、ベンダーの終了に備えた出口を求められる場合、StudioよりWebflowのほうが説明しやすいと考えられる。逆に、社内に開発者がおらず、書き出したコードを持っていても扱えない組織にとっては、この差はあまり効かない。アプリの機能や決済まで同じ場所で持ちたい場合は、Webflowの守備範囲のほうが広い。
:::

## AIの入り方

:::fact
Studioはエディタの中にImage AI、Text AI、Auto Responsive、Layer Rename、SEO Writing Assist、Embed Code AIを持ち、実行回数には上限がある。別売りのStudio.Assistantは年払いで月19,800円からで、ヒアリングからドラフトまでを扱う。Studio.Dropは稼働中のサイトを取り込んでAIとの対話で運用する新サービスで、ClaudeやCodexとのMCP接続をうたい、2026-11-02時点では招待制のクローズドβだ。Webflowの料金ページは、Webflow AIとMCPサーバーを無料のStarterの項目にも並べ、製品ページはサイト構築、コピー生成、コード生成、SEO・AEOの改善を説明する。Teamプランには共有のAIクレジットが年100,000含まれる。Source by Webflowは、マーケティングチームとエージェントのための新しいプラットフォームとして、limited research previewの段階にある。
:::

:::guess
両社とも「運用をエージェントに任せる」方向を指している点は似ているとみられる。違いは売り方だ。Studioは制作者の初期工程を圧縮するAssistantを高めの別料金で売り、Webflowは同じプラットフォームの中にAIをクレジットで組み込み、企業向けにはAEOエージェントを上位プランに置く。どちらも新しい製品は提供が始まったばかりなので、この項目で選ぶより、今のエディタの体験で選ぶほうが安全と考えられる。
:::

## セキュリティと預ける情報

:::fact
Studioのセキュリティページは、Google Cloud上の東京とアイオワのリージョン構成、Google Cloud ArmorのWAF、TLS 1.3以上の強制を説明し、料金ページはISO/IEC 27001:2022とISO/IEC 27017:2015を載せる。SAML 2.0・OIDCのSSOはEnterpriseプランで提供する。Webflowのセキュリティページは、ISO 27001、ISO 27017、ISO 27018、ISO 42001、SOC 2を掲げ、SOC 2 Type IIに準拠していると説明する。すべてのサイトでTLS 1.2以上と保存データの暗号化を提供し、脆弱性の報告窓口も設けている。
:::

:::fact
Studioは2026年10月16日に、第三者が同社のクラウド環境に不正アクセスし、全利用者について、アカウント情報、デザインとCMSの内容、フォームの送信内容、外部サービスのAPIキーなどが外部に流出した可能性があると公表した。実際に取得された事実は確認できていないが、取得されたものとみなして対応しているという。脆弱性は修正済みで、対象件数、二次被害の調査結果、原因と再発防止策は2026-11-02閲覧時点で続報待ちだ。この比較では、Webflow側の過去のセキュリティ事案は調査していないので、同じ基準で両社を比べたものではない。
:::

:::guess
どちらを選ぶにしても、フォームで個人情報を集めると、その回答はサービス事業者の環境に保存されることになる。Studioの件では、保存を無効にしていた間の回答や、Googleフォームなど外部サービスの埋め込みは対象外と説明された。個人情報の量が多いサイトなら、回答を保存しない設定や専用のフォームサービスの利用を、どちらのサービスでも検討する余地があると考えられる。すでにStudioを使っている人は、公式の案内に沿ってパスワードやAPIキーの切り替えが済んでいるかを確認しておきたい。これから選ぶ人は、続報で示される原因と再発防止策を判断材料に含めるとよい。
:::

## どんな人にどちらが合いやすいか

ここからは、上の条件を当サイトが読んだうえでの整理だ。優劣ではなく、どの条件が効くかを示す。

:::guess
- 日本語の小規模サイトやLPを安く独自ドメインで出したい場合は、Studioが合いやすいとみられる。Miniは年払い月590円で、2ページという制約に収まるなら最も小さく始められる。
- 社内のマーケターや非エンジニアが更新を担うコーポレートサイトや採用サイトも、Studioの入口の低さと円建ての請求、チャットサポートが効くと考えられる。Businessの年払い月3,980円で300ページとCMSモデル10まで使える。
- フロントエンドの知識があり、CSSの細部まで制御したい人や、海外向けのサイトを多言語で運用したいチームは、Webflowのほうが合いやすいとみられる。TeamにはLocalizeが2ロケール含まれる。
- ベンダーの終了に備えて出口が必要な案件は、Webflowの書き出しが判断材料になる。Studioには出口がない。
- 記事が1万件を超えるようなメディアは、StudioのBusiness Plusは合計15,000件・1モデルあたり10,000件が目安で、WebflowのPremiumは20,000件だ。どちらも上限を確認し、将来の規模でEnterpriseになるかどうかを先に見積もりたい。
- サイトの横でアプリや決済を動かしたい場合は、Webflow CloudとEcommerceを持つWebflowの範囲が広い。Studioでは外部サービスを組み合わせる。
- 制作会社やフリーランスが日本の顧客に納品する場合は、Studioの納品後の運用が月額課金として積み上がること、StudioのStoreやWorksの仕組み、顧客への説明責任まで含めて考える必要がある。Webflowはチーム向けのTeamが月2,500ドルで、個別サイトのプランとの間の差が大きい。
:::

## なぜ設計がここまで違うのか

:::fact
[Studioの解剖記事](/ja/articles/studio)によれば、Studioは2016年創業の日本企業で、利用者は90万人以上、公開サイトは25万件以上。沿革に載る調達は3回で計5.3億円だ。Webflowの公式サイトは、2013年創業、利用組織30万、累計調達3.35億ドルと掲げている。
:::

:::guess
設計の違いは、最初にどの市場を見たかの違いから来ているとみられる。Webflowは英語圏のWeb制作者を相手に、CSSという共通語をそのまま道具にし、書き出しという逃げ道を残すことで専門家の信頼を得てきたと考えられる。Studioは日本のデザイナーと中小企業を相手に、サーバーやコードの話そのものを視界から消す方向に進んだと考えられる。

その結果、Webflowは「Webの標準に寄り添う」ことを、Studioは「全部引き受ける」ことを差別化にしてきた。どちらの道にも代償がある。Webflowの代償は学習の重さで、Studioの代償は預ける範囲の広さだ。
:::

StudioとWebflowのどちらが優れているかより、自分のサイトを誰が更新し、何年続け、いつか外へ出す必要があるかを考えたほうが答えに近い。社内の誰もが触れて、日本語がきれいで、サーバーのことを忘れたいならStudioの条件が合う。CSSを知る人が設計し、海外にも出し、出口も確保したいならWebflowの条件が合う。料金表の差はその次に見れば足りる。
