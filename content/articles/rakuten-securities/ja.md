ネット証券の手数料競争は、2023年に行き着くところまで行った。楽天証券も同じ年の10月に国内株式の取引手数料を無料にした。それから3年で、同社の営業利益率は35%台に上がり、総合口座は1,439万になった。手数料という看板を外しても、なぜ稼げているのか。答えの半分は、口座に積み上がる残高から入る収益にある。もう半分は、その残高を運んでくる経路にある。積立の代金は楽天カードを通り、ポイントは楽天のものが使われ、待機資金は楽天銀行に置かれる。楽天証券は、楽天の決済網の出口に建てられた証券会社だと読むと、数字のつながりが見えてくる。

## サービス解説

楽天証券は、国内株式、米国株式、投資信託、債券、FX、先物・オプション、iDeCoなどをウェブとアプリで扱うオンライン証券だ。対面の店舗は持たず、独立系のフィナンシャルアドバイザー（IFA）を通じた販売も手がける。

:::fact
同社の「業務及び財産の状況に関する説明書」によれば、前身のディーエルジェイディレクト・エスエフジー証券は1999年3月に設立され、同年6月にインターネット取引の営業を始めた。2003年11月に楽天（現・楽天グループ）が株式の96.7%を取得して親会社となり、2004年2月に楽天とのポイント提携を開始、同年7月に楽天証券へ社名を変えた。2004年の時点で、ポイントはすでにこの会社の歴史に入っている。会社概要によれば、資本金は194億9,500万円、従業員数は720名（2025年12月現在）だ。
:::

:::fact
2026年12月期上半期の決算説明会資料（2026-08-04）によれば、2026年6月末の総合口座数は1,439万（前年同期末比14.5%増）、NISA口座は792万、預り資産は58.7兆円（同48.3%増）、投資信託残高は25.8兆円（同69.2%増）。総合口座の稼働率は67.4%で、稼働口座は970万。総合口座に占める楽天会員の比率は86.7%だ。第3四半期決算のお知らせ（2026-10-29）によれば、2026年1〜9月の連結営業収益は1,659億7,800万円、営業利益は550億9,300万円、親会社株主に帰属する四半期純利益は285億8,100万円だった。前年同期はそれぞれ1,123億3,800万円、295億1,900万円、143億5,700万円だ。
:::

:::fact
資本の形は、この会社を理解するうえで欠かせない。会社概要によれば、株主は楽天証券ホールディングス（51.0%）とみずほ証券（49.0%）。2023年11月9日の楽天グループの開示によれば、みずほ証券は2022年に取得した19.99%に約29.01%を追加し、譲渡金額は870億円となる見込みで、取得後も楽天証券は楽天グループと楽天証券ホールディングスの連結子会社だとされた。さらに楽天グループの2026年10月1日の発表によれば、フィンテック事業の再編が同日に効力を発生し、楽天カードと楽天証券ホールディングスは楽天銀行の連結子会社となった。2026年5月20日のみずほFG・みずほ銀行・楽天銀行の開示は、みずほと楽天カード・楽天証券の業務提携関係は再編後も変わらないとしている。みずほ銀行は同じ再編を通じて、楽天銀行の議決権の10.52%を持つ主要株主になる見込みとされた。
:::

## UX分析

楽天証券のUXの中心は、取引画面より前にある。「楽天の会員が、いつもの支払い手段のまま投資を始められる」ことだ。一方で、手数料を無料にする条件の設計には、この会社の執行の考え方が表れている。

- **積立の支払いを、楽天の決済に寄せる**。決算説明会資料によれば、2026年6月末時点で投信積立の設定者の93.1%が楽天グループ連携の決済手段（楽天カード、楽天ペイ残高、楽天銀行など）を使っている。公式ページによれば、クレカ積立は毎月100円から10万円まで、楽天ペイ残高決済は毎月最大5万円までで、どちらもNISAで使える。
- **カードの種類で還元が変わる**。ポイント案内によれば、楽天カードは0.5%、ゴールドカードは0.75%、プレミアムカードは1%、ブラックカードは2%。代行手数料が年率0.4%（税込）以上の銘柄では、ブラック以外も1%になる。2026年9月28日のお知らせによれば、ブラックカードは2027年1月買付分から、前年のショッピング利用額が400万円以上なら3.2%、未満なら2.0%に変わる。
- **ポイントで買える範囲が広い**。楽天グループで貯めたポイントを1ポイント1円として、投資信託、国内株式（現物）、米国株式（円貨決済）、バイナリーオプションの購入に使える。ポイントプログラムのページは、95%の顧客が楽天ポイントコースを選んでいると記す。決算説明会資料によれば、稼働口座のうちポイントを獲得または利用した口座の比率は63.8%だ。
- **証券の利用が、買い物の還元率に跳ね返る**。ポイント投資で投資信託を月3万円以上買うと楽天市場のSPUが0.5倍上がり、米国株式（円貨決済）でも同じ条件で0.5倍上がる。楽天ポイントコースとマネーブリッジの設定が条件だ。投資と買い物が、同じ会員ランクの中でつながっている。
- **銀行残高に金利で理由を与える**。楽天銀行と口座を連携するマネーブリッジの利用者は680万人で、利用率は47.7%、利用者の普通預金残高は6.6兆円（決算説明会資料）。公式ページによれば、2026年11月2日時点の優遇金利は普通預金1,000万円以下の分が年0.58%、1,000万円超の分が年0.52%だ（いずれも税引前）。
- **少額の入口を増やす**。単元未満株の「かぶミニ」は、現物取引の取引者の37.2%が使う。2025年7月に始めたNISA限定の「かぶピタッ」は100円以上1円単位で金額を指定できる。2026年1〜6月の新規口座開設者の82.9%は投資経験なしと答えた層だった。

:::fact
手数料無料の条件は、競合と形が違う。公式の手数料ページによれば、ゼロコースはインターネットでの国内株式（現物・信用）の取引手数料が約定代金にかかわらず0円で、原則として同社が指定するSOR注文の利用が必須となる（指定の取引ツールや注文形態で発注する場合を除く）。ゼロコースを設定するには、SORとRクロスの内容を理解して利用に同意する必要がある。Rクロスは同社が提供する社内取引システム（ダークプール）で、投資家同士の注文を付け合わせ、対当する注文があれば取引所の立会外市場（ToSTNeT）に発注して約定させる。SORのページによれば、接続先は東証、JAXPTS、ジャパンネクストPTS、Rクロスの最大4市場で、価格改善の効果は外部機関の株式会社QUICKによるレポートとして毎月公開している。ゼロコース以外には、1約定ごとの超割コースと、1日定額のいちにち定額コースが残っている。オペレーターを通した注文は3,795円（税込）からだ。
:::

:::fact
NISAでは、公式ページによれば国内株式・ETF、米国株式、海外ETFの取引手数料が無料だ（中国株式とアセアン株式は対象外で、かぶミニやかぶピタッには別にスプレッドがある）。課税口座の米国株式は約定代金の0.495%（税込）で、上限は22米ドル（税込）。日本円で買うときは1米ドルあたり25銭の為替手数料が為替レートに含まれる。NISAの実績では、日本証券業協会の集計（証券会社10社・2026年6月末時点）をもとに同社が示すシェアが、口座数で39.9%、購入金額で38.7%。2026年1〜6月のNISA購入金額は約4.0兆円で、うち68%が成長投資枠だった。2027年1月から始まるこどもNISAは、2026年10月から開設手続きの受付を始めるとしている。
:::

:::guess
ゼロコースがSORとRクロスへの同意を条件にしているのは、無料の見返りに、注文を自社が設計した執行経路へ集める狙いがあるとみられる。ただし、これを会社の都合とだけ読むのは一面的だ。公式の説明では、SORは東証の最良気配より有利か同値の価格でPTSに発注することを目指しており、外部機関のレポートも公開している。顧客にとっても価格改善の余地がある仕組みだと読むこともできる。どの程度の効果があるかは、ログイン後に見られるレポートで個別に確かめる必要がある。
:::

:::fact
UXの弱点が表面に出たのは、2025年の不正アクセスだ。同社の補償方針（2025-07-25、2026-02-18更新）によれば、2024年末から発生した事案について、社内調査の結果、同社システムからのID・パスワード・取引暗証番号の漏えいや資産の流出はなく、フィッシング詐欺やマルウェアによってログイン情報が不正に取得され悪用されたものと認識しているとする。約款上は免責に該当するとしながらも、金融機関としての社会的責任を勘案し、被害額の50%を基本に金銭で補償し、売買手数料を返金し、一律1万円のお見舞金を支払う方針を示した。元々保有していた有価証券が不正に売却された分は被害額の算定対象外で、お見舞金の対象とされている。絵文字を使うログイン追加認証は2021年に導入していたものの、その重要性や利用を十分に周知できていなかった点を反省するとも記している。
:::

:::fact
対策はその後に積み上がった。決算説明会資料によれば、2025年3月以降にリスクベース認証を導入し、2025年6月1日に絵文字のログイン追加認証を全チャネルで必須にし、2025年10月1日にサイバーセキュリティ本部を新設し、2025年10月26日にパスキー認証（FIDO2）を全顧客・全チャネルへ導入した。2026年6月からはパスキーの必須化を段階的に進めている。パスキーを設定すると、ログインID・パスワードでのログインは併用できなくなる。補償方針は、対策の実施後、2025年5月上旬以降は同様の不正アクセスと被害を確認していないと記す。損益への影響は決算短信に表れており、2025年12月期の特別損失に支払補償金8億5,800万円が計上された。
:::

:::fact
別の事案として、同社は2026年10月31日に、「デジタル特典付き社債」の特典申込に使う外部サービスの提供元であるNTTデータから、委託先のシステムが不正アクセスを受け、3銘柄を購入した一部の顧客の情報、延べ362件が持ち出された可能性があるとの報告を受けたと公表した。同社のシステムが不正アクセスを受けたものではなく、ログインに必要なID、パスワード、取引に必要な情報は含まれないとの報告を受けており、公表時点で本件に起因する不正アクセスや不正取引は確認されていないとしている。原因は調査中だ。
:::

## 技術構成

## ビジネスモデル

楽天証券の収益は、大きく分けると、売買に連動するフローと、残高に連動するストックでできている。同社はこの区分で自ら数字を公表している。

:::fact
第3四半期決算のお知らせによれば、2026年1〜9月の営業収益1,659億7,800万円の内訳は、金融収益743億4,300万円、トレーディング損益320億8,900万円、委託手数料242億2,100万円、その他の受入手数料232億4,600万円などだ。金融収益の割合は44.8%、委託手数料は14.6%にあたる（当サイトの計算）。金融費用177億5,100万円を引いた純営業収益は1,482億2,600万円。貸借対照表では、2026年9月末の信用取引貸付金が1兆6,270億8,700万円で、2025年12月末の1兆1,398億1,600万円から増えた。
:::

:::fact
決算説明会資料の「収益の分散化状況」によれば、2023年1〜6月と2026年1〜6月を比べると、株式の比率は29.6%から18.2%へ下がり、投資信託は17.0%から19.7%へ、金融収益は32.5%から44.1%へ上がった。2026年4〜6月期のストック収益は281億円（前年同期末比67.8%増）で、販売管理費315億円の89.3%をまかなった。資料はストック収益を、投信代行手数料や金融収支など残高や暦日数に連動する収入と定義している。取引手数料の無料化については、2025年12月期の資料が「無料化による取引手数料の減少分を、受入手数料の増加分で相殺」と説明し、営業利益は2023年の285億円から2025年の445億円に増えた。2026年4〜6月期の営業利益率は35.9%だった。
:::

:::fact
費用の側にも特徴がある。2025年12月期の販売費・一般管理費1,028億3,300万円のうち、取引関係費が611億8,200万円で59.5%を占め、人件費は82億100万円、広告宣伝費は119億1,900万円（資料では取引関係費の内訳に置かれている）、事務費は158億600万円、減価償却費は116億1,200万円だ（割合は当サイトの計算）。2026年1〜6月は取引関係費が386億700万円で、前年同期比35.3%増えた。
:::

:::fact
信用取引の金利は、手数料無料の裏側で収益を支える行だ。公式ページによれば、国内株式の買方金利は制度信用が年2.80%（優遇2.28%）、一般信用が年2.80%（優遇2.10%）で、いちにち信用は年0.00%。貸株料は年1.10%が基本だ。決算説明会資料によれば、2026年4〜6月期の金融収益は258.7億円で、うち信用収益が127.4億円、信用以外が131.3億円。資料は金利上昇にともなう財務収益の改善が貢献したとしている。
:::

:::fact
投資信託では、2026年4〜6月期の関連収益が74.0億円（前年同期比64.3%増）、保有者は712万人、積立設定額は月3,171億円で、設定者の割合は78.7%だった。IFA経由の顧客は24.4万人で、預り資産は3.0兆円。ロボアドバイザーは3サービス合計で3,900億円。上の層に向けては、準富裕層以上を対象にオンラインと社員のコンサルタントを組み合わせる「Star CLUB」を来春本格開始の予定としている。投信残高に応じたポイントは、楽天・プラスシリーズなど対象の6本に限られ、それ以外のファンドは残高が基準に初めて達したときに付与する別の仕組みだ。
:::

:::fact
公式のアフィリエイトプログラムのページは、提携会社としてリンクシェアとTGアフィリエイトを挙げ、口座開設の申込件数に応じて報酬を支払うとしている。審査があり、外務員登録のない者は証券取引の勧誘や個別商品の説明をしないよう注意書きを置く。報酬額は同ページには書かれていない。
:::

:::guess
取引関係費が販管費の6割近くを占めるのは、人を抱える代わりに、集客・取引所・情報・決済の周辺で変動費を払う事業だからとみられる。公開資料では明細までは確認できなかったが、IFAへの支払いや、楽天グループの決済やポイントに関わる費用がここに入っている可能性がある。もしそうなら、売上が増えるほど費用も増える一方で、グループ全体で見れば費用の一部は楽天の別の会社の収入になる。楽天証券単体の利益率だけでは、グループが積立経由で得ている価値を測れないと推測される。
:::

:::guess
みずほが49%を持つ意味は、資本の出し手が増えたことだけではないとみられる。楽天の側には若い層と少額の積立が集まり、新規口座開設者の58.0%は30代以下だ。みずほの側には法人顧客、IPOや債券の引受、対面のコンサルティングがある。IFA、職域のつみたてNISA、IPO、みずほ銀行の残高表示といった連携は、顧客の資産が増えて相談が必要になる段階を、グループの外へ逃がさないための設計と読める。一方で、2026年10月の再編により持株会社は楽天銀行の傘下に入り、みずほ銀行は楽天銀行の株主にもなる。楽天とみずほの間の役割分担が今後どう変わるかは、公開資料からはまだ読み切れない。
:::

:::guess
このモデルの強さと弱さは同じ場所にある。楽天の決済網に乗ることで、積立は毎月自動で流れ込み、残高は積み上がる。ストック収益が販管費の9割近くをまかなう水準まで来たのはその成果だ。ただ、金融収益の半分近くは信用取引に連動し、2026年の数字は日経平均の最高値圏と日銀の利上げという追い風の中で作られている。さらに、カードの還元率のように、楽天グループ内の条件ひとつで魅力が変わる部分もある。2022年の還元率改定を経ても積立が伸び続けたことは粘り強さの証拠だが、相場が冷えたときに信用残高と金融収益がどこまで残るかは、まだ試されていないと推測される。
:::

楽天証券は、証券会社というより、楽天経済圏の中で「余ったお金の行き先」を担う部門に近い形をしている。カードで払い、ポイントで買い、銀行に待機させ、気づけば残高が積み上がる。その仕組みの上で、手数料はゼロになっても利益は増えた。ただ資本の側を見ると、この会社はもう楽天だけのものではない。みずほの対面と引受、楽天銀行の預金が同じ図の中に入ってきた。手数料無料の次に問われるのは、この入り組んだ所有構造の中で、誰が顧客のお金の面倒を最後まで見るのかという点だ。
